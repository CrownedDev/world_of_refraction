Adds core turn-based combat foundation with turn debt system and

## New Systems

### TurnManager (GameInstanceSubsystem)
- Turn debt calculation with speed-based ratios (3:1, 2:1, etc.)
- 7-level tie-breaker cascade (Speed → AttackSpeed → Underdog → Stats → Team)
- Dynamic speed change handling (recalculates ratios on buffs/debuffs)
- Death/resurrection support (dead characters skip turns)
- Turn order preview (simulates next N turns without state mutation)
- Event system (OnTurnStarted, OnTurnEnded, OnSpeedChanged, OnCombatEnded)
- Comprehensive debug tools (print order, debt details, context menu)

### CharacterDataComponent
- Runtime character state wrapper for CharacterData assets
- Server-authoritative HP/EP management
- Full network replication (DOREPLIFETIME)
- Event broadcasting (OnHPChanged, OnEPChanged, OnDied, OnResurrected)
- Automatic initialization from CharacterData template
- Separates static data (asset) from runtime state (component)

### TurnManagerTestActor
- Automated test suite with 5 comprehensive tests
- Verifies speed ratios, tie-breaking, speed changes, death/resurrection
- Context menu execution for easy testing
- Expected output: "5 passed, 0 failed"
