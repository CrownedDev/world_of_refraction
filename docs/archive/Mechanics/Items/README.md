# Items

The Items family — three kinds of slot-in / use items:

- **[Crystals](./Crystals.md)** — consumable elemental gems (the 10-gem roster) and the
  Broken Darkness three-way interaction.
- **[Augment Stones](./AugmentStones.md)** — mechanical bonuses (damage, defense, speed…); most are
  dual-form (attach permanently OR use as a temporary buff).
- **[Fusion Stones](./FusionStones.md)** — player-made stones fused from two attachables.
