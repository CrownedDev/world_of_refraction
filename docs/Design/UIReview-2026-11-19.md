# UI review: the menu pages (2026-11-19)

**Why:** Crown play-tested the Equipment tab with the 12-weapon test set and asked for a better screen; the v3 grid draft "could be better". This page says what works and what doesn't, page by page, and proposes new mockups. **Nothing is built from them until Crown approves one** (FeelGuide care: one piece at a time).

## Page by page

### Pause menu (`menus/pause`, built B-439)
- **Works:** page list, the party with HP / EP / tier, a preview panel. Short, one press to every page. Matches Expedition 33's and Persona 5's pause screens.
- **Doesn't:** nothing blocking. Keep it.

### Equipment tab (live: `ULoadoutV2ScreenWidget`, C++ only)
- **Works:** the rules are separate and tested (`WoRLoadoutV2`); refusals are shown with their reason; Compare exists; the list now scrolls and a weapon shows its type.
- **Doesn't:**
  - **Slots and choices are never on screen together.** The Add / Edit window reuses the one list: kind, then slots, then choices, one after another. This is Crown's main complaint.
  - **Text where pictures should be.** One-line rows, names and tags; no picture of the piece; the tier is sometimes a letter in the text.
  - **Compare is a text line** under the box ("Equipped 40 / Selected 46 · ..."), not beside each stat.
  - **Long hint bar:** up to six verbs at once.
- **v2 mockup (approved 2026-11-13):** fixed the side-by-side in the Add gear window, but it is still lists, and the window covers the loadout.
- **v3 draft (today):** right direction (grid + picture), but: the left column holds both the set list and an "Editing" block, so slots are small and labels 12 px; the tier badge sits on the art; "M / O" letters need a legend; the filter chips run to the panel edge; the details picture takes a third of the panel while there's no compare; half the grid is empty rows.

### Skills tab (v2, built)
- **Works:** the highlighted skill's row is always open with every number (Expedition 33's skill list does the same). Skills are mostly text, so a list is right here: **no grid**.
- **Doesn't:** the left column is mostly empty. Later, show the entry's weapon picture there (as in Equipment v4). Not urgent.

### Apparel tab (v2, built)
- Same problem as Equipment (one list, no picture). **Use the Equipment v4 layout** (two slots on the left, the grid, the panel). Not drawn: it is the same screen with coats in the grid.

### Inventory (`menus/inventory`, built B-441 / B-461 / B-543)
- **Works:** a grid with counts; verbs greyed with reasons; three tabs (Gear, Pouch, Chest) plus the Loadout shortcut.
- **Doesn't:**
  - **Letters instead of pictures** ("W", "C", "Ap" in hexagons): you can't tell a sword from a bow.
  - **The details panel has no picture**, and the verbs are a small pop-up box inside it.
  - **Two inventories look different:** the loadout screen's own Inventory tab (D-230) is a list; the Inventory screen is a grid.
- **v2 mockups:** the same tiles and pictures as Equipment v4, the actions as buttons in the panel (Crown's reference), the worn tick in the corner.

### Character sheet, Party, Journal, Settings
- Not reviewed in depth this pass (no complaint from play-tests). They already share the header, tabs and footer.

## What the new mockups change, and the games behind it

1. **Slots, grid and details on one screen, no window.** Pick a slot on the left, the grid shows what you own for it, the panel shows the focused piece. *Elden Ring's* equipment screen works this way (slots, then a grid of what fits with the info panel beside it); *Baldur's Gate 3* and *The Witcher 3* keep the paper doll beside the bag. Fixes the main complaint.
2. **A filled slot shows the piece, its type and tier; an empty one shows the slot word and what it takes** (Crown). The lit slot has an arrow pointing at the grid.
3. **Pictures, not words, in the grid and the filter row.** Count bottom-right, tier bottom-left, a violet tick for worn, a lock for "can't go here". *Diablo IV* and *BG3* grids read at a glance this way.
4. **Compare beside each stat:** "40 → 46" in green, "Fast → Normal" in red, against what the slot wears. *Diablo IV*'s and *Destiny 2*'s compare tooltips are widely liked for exactly this; *Persona 5*'s equip screen shows arrows per stat.
5. **Pieces that don't fit stay in the grid, greyed with a lock, sorted last**; the reason shows in the panel (UI_Theme §5: disabled stays focusable to show why).
6. **Actions are buttons in the panel** (A Equip to Off hand, X Compare, Y Sort), so the bottom bar only keeps navigation (Crown's reference; *Monster Hunter World*'s equipment box works the same).
7. **Cells as pips at the top right**, a pick's cost shown in amber before you confirm (*Expedition 33*'s Pictos points).

## Open choices for Crown

1. **Variant A (fixed panel) or B (tooltip)?** Recommendation: **A**. With a gamepad the panel never covers the grid, and it is where Elden Ring and Expedition 33 put details. B fits more pieces on screen (Diablo IV, Destiny 2) but the tooltip hides part of the grid. Either way, a mouse hover can show the same details.
2. **Pieces that don't fit: show them greyed (as drawn) or hide them** behind a "Fits" filter? Recommendation: show them greyed (the game's rule: refusals stay visible).
3. **Keep the loadout screen's own Inventory tab?** With v4, the Equipment grid already shows every piece you own for a slot, so that tab repeats it. Recommendation: drop it and keep the Inventory screen (Gear, Loadout, Pouch, Chest) as the one inventory. This changes D-230, so it is Crown's call.
4. **Pictures per weapon:** each weapon gets its own icon (new art, an editor job) or every weapon of a type shares the type's picture (works today). The mockups draw one picture per type.
5. **Inventory "Equip..."** opens the Equipment page with that piece focused (drawn as "Equip..."). OK?
