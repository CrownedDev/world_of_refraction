# Showcase references

**2026-11-12.** Look-and-timing references for the visual phase (showcase battle, `ShowcaseBattlePlan.md`), passed on by the desktop operator. **From recall: check each in the game before relying on it.** Every piece is also checked against `FeelGuide.md` and the E33 study rules (`analysis/MaelleCombatPresentationStudy.md` R1–R18). The asset inventory for the same items is `ShowcaseInventory.md`.

Database pages: brokenbuilds.gg/expedition-33/skills, jegged.com (FF16 Abilities).

## Scope (Crown, 2026-11-12)

- **Gear:** 2 weapons (one melee, one ranged/caster), 2 adapters, 2 evolutions.
- **Spells (Generic, take the caster's element), one per school:** Destruction = **Elemental Bolt**; Conjuration = **Elemental Lance** (a conjured lance thrown or driven at the target); Enhancement = a buff; Restoration = a heal; Manipulation; Impairment = a debuff.
- **Projectiles to tune:** fast bolt, slow heavy orb, volley, arcing lob, homing, piercing beam/line.
- **Weapon abilities**, per weapon, themed on the schools (theme only, no school slot limits: Q1): Destruction = light hit, heavy hit, finisher; Impairment = crippling strike (slow/stagger); Manipulation = taunt; Restoration = self-heal (second wind); Enhancement = battle cry (self or party buff); Conjuration = none.

## Spells

| Spell | Reference | What to copy |
|---|---|---|
| Elemental Bolt | FF16 fire abilities | ~0.2 s wind-up, travel under 0.3 s, hit-stop + shake on impact, scorch decal |
| Elemental Lance | E33 conjured-weapon skills | Forms from light motes in the hand; the hold before the throw is the telegraph |
| Buff | Star Rail / E33 party buffs | Aura ring on each target + an icon pop |
| Heal | FF16 Phoenix support | Slow rising gold/green motes, soft bloom |
| Manipulation | BG3 Misty Step | Blink effect at both the start and the end point |
| Debuff | Persona 5 Rakunda family | Down-arrow icon + a short flash |
