# Economy and runs

This page covers the currencies, what a fight and a run pay out, what carries over between the hub, a trial and a battle, shops, upgrading, merging, dismantling, crystal wear repair between fights, drop quality, the shared gear pool, and how an encounter is put together. It leaves classes, slots and loadout budgets to 01-classes-and-loadouts.md, damage to 02-elements-and-damage.md, status bars to 03-status-bars.md, how wear is worked out during a cast to 04-effects-and-turns.md, and who is in your party to 06-party.md. Paths are relative to `Source/world_of_refraction/`.

## Currencies
**Names (D-159, B-366):** the two main currencies swapped their **player-facing** names. The **run** currency is shown as **Prisms**; the **hub** currency is shown as **Gold**. The code names stay (`ECurrencyType::Gold` = run, `ECurrencyType::Prisms` = hub, D-058), and so do the rows below written before the swap: in them, "Gold" is the run currency and "Prisms" the hub one. Rows written after it use the new names.

## Conflicts
- **Cx-1 — In-run shops charge Prisms.** D-002 notes say buying uses Prisms in the hub and Gold in a run (`MerchantData.h:9-11` agrees). The code always charges Prisms (`EconomyService.cpp:853,875`) and never checks a merchant's hub/trial tags (`MerchantData.h:100-109`, no callers). Decided (D-002); **resolved (brain default 2026-11-04):** shops charge the currency of the place, built in **B-366c** (in game: `UEconomyService::GetPlaceCurrency`, `PurchaseCostBalances::PaidFrom`). What Gold buys is **D-048**.
- **Cx-2 — Win and loss both return to the trial.** D-002: win = continue with the enemy beaten; its lose half is replaced by D-155. Code: both return to the trial (`BattleGameMode.cpp` `HandleCombatEnd` → `ReturnToTrial`). The win half is built: since B-184 a won fight's enemies stay beaten for the run (ER-11). The loss routing is built in **B-362** (D-155, replacing B-072; ER-12): a wipe returns to the trial, or to the hub when the run is over.
- **Cx-3 — Durability doesn't carry over between fights.** D-013 says HP, EP, absorption and durability carry over within a run. Only HP and EP are banked (`BattleGameMode.cpp:260-298`); crystals are rebuilt from authored data on every level load (`TrialRunSubsystem.h:12-17`), so +10 repair (ER-36) and wear never reach the next fight. Absorption isn't banked either. **Resolved by B-115:** crystal and absorption state are banked next to the vitals and restored on the next spawn (ER-14).
- **Cx-4 — Where you can upgrade.** D-002: upgrades in the hub and during a run. `docs/Mechanics/Economy/Hubs.md` (composition table) says upgrade, repair and merge are run-only and the hub only buys and downgrades; it also describes a "draft 3 inventories / return for Gold" run start that D-021 replaced. Question, options and recommendation: **D-047**. - **Cx-5 — Prisms and essence: per character or per player?** D-002 keeps Prisms across runs and D-020 makes the gear pool one per player, but the wallet sits on each character, Prisms and Diamond included (`CurrencyComponent.h:15-24`), so a party of three has three wallets.
