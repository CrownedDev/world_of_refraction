# Classes and loadouts

This page states what each class is, what a character can equip, and what that gear lets it do in a fight: the three classes, loadout slots and caps (the Resonator budget, item slots), weapons, adapters, the attachments (crystals, augment stones, fusions, evolutions) as far as they decide what a character can use, the Refractor's innate spell pool, and how world-pillar requirements affect using a skill. Damage numbers, elements and resistances are in 02-elements-and-damage.md; status bars in 03-status-bars.md; what effects do and how turns and costs run in 04-effects-and-turns.md; Gold, Prisms, upgrades and runs in 05-economy-and-runs.md; party size and control in 06-party.md. Code paths are relative to `Source/world_of_refraction/`.

**Adapter (D-107):** the gear that channels spells is an **adapter**; a ring is one form of it (others: pistols, trainers). The form changes only looks and animation. Code and citations still say `Ring` until the move-only rename (B-299).

## Gaps

- No basic attack without a weapon: a Refractor with an adapter or evolution primary, or a Resonator with an evolution primary, has no Attack (CL-16, CL-17). Stunned, it can only Defend (D-001/D-023). No rule says whether an unarmed attack should exist. **Ruled (Crown, 2026-10-26, rules review): keep it. No weapon, no basic attack: a character without a weapon has traded it for literal powers, so they cast.** The logic behind it should be tidied (one clear check for "has a basic attack"), with no change in behaviour.
- No class passives. The deckbuilder gives Generic +1 Physical Resistance, Resonator +1 Resistance per keyed adapter element, and Refractor +3 Amp (a flat damage boost) and +1 Resistance to its innate (`wor-deckbuilder/docs/reference/01-card-model.md`, "Class passives"). D-027 left these unruled. **Ruled (Crown, 2026-10-26, rules review): no class passives; the classes are already unique through their slots and rules.**
- No rule ties an ability to a weapon type. Abilities are assigned to whatever weapon holds them. The deckbuilder lists the weapons each ability needs, e.g. "2 Swords" (`01-card-model.md`, "An Ability's RequiredWeapons"). **Outdated (2026-10-26):** abilities carry `RequiredWeaponType`, and the one loadout rule set (B-028) enforces it, with tests.
- No rule for a skill whose source goes away mid-fight (an adapter breaks, a crystal breaks). The deckbuilder lets such a skill stay placed but refuses its use (`01-card-model.md`, "A skill can be placed while its need is unmet"). **Ruled: D-083** (greyed out with the reason; broken adapter crystal → F-tier spells only; broken weapon crystal → no infusing or elemental abilities). Built in B-163 (`ULoadoutComponent::GetBrokenSourceReason`, `SourceBreakRules.h`); infusing through a broken adapter: **Q-163 = B**, it is no infusion source (fix/Q-163-broken-ring-infusion). **Q-163b = B** (approved by default): those F-tier spells cast plain: no infusion through any source, and a Generic one is non-elemental. The AI casts them too (B-197, `UAIDecisionManager::GetUsableSpells`). Both of a Generic's weapons are checked; a spell on two sources follows the one the cast uses (innate, intact adapter, primary weapon, secondary): **Q-204 = A** (approved by default, B-204).
- Generic's secondary slot can't hold an adapter (`HasRingInSecondary` always returns false, `Private/Loadout/LoadoutComponent.cpp:2483-2511`). Nothing says whether it should. **Ruled (Crown, 2026-10-26, rules review): weapon only. An adapter goes only in the primary slot, as for everyone else.** The always-false `HasRingInSecondary` can be retired once checked unused.
- No equip, socket or loadout screen exists: every rule above can only be exercised through data-configured loadouts (`docs/Mechanics/Gear/Loadout.md`). Covered by the UI rebuild (D-024) and the placeholder-UI rule.
