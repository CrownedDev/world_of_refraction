### B-517: the skills you pick live on what is worn (skills track S1, part 1)

- **What changed:** the skills and spells you put in a weapon's or a ring's slots are now stored on the worn entry (the place in the loadout that holds the piece), not on the piece. So a preset keeps its own skills for the same sword, and giving the sword away doesn't take them along. The class kit's starting skills go on the kit's entry. `wor.Loadout.PrintWorn` lists each entry's picks.
- **Why:** D-224 says gear carries no skills; this is the first half of the plan's stage S1.
- **How it was checked:** build and the full suite (2238 passed, 0 failed; validation 18 known, 0 new). wor-reviewer (Sonnet, two passes) found that every loadout but the worn one lost its picks on a map change or a reload (custom loadouts go through the pool's saved form); fixed: each custom loadout keeps its entries' picks, with specs.
- **Known limits:** a piece swapped into an entry starts with empty slots; edits while a run holds the record (gear left at home) aren't kept.
- **Left for part 2 (B-518):** the built-in skills still pre-fill the slots you haven't changed.
- **For Crown:** `docs/PIE/B-517.md`. Old saves are wiped once (save version 42).

### B-516b: same-named pieces are told apart by tier first

- **What changed:** two pieces with the same name and different tiers (a C and an F "Lightning Ring") no longer get a number; the tier tells them apart. On the Equipment list every entry row now shows its tier badge. The quick strip has no badge, so it adds the tier letter ("Lightning Ring  C") when one name is held by two tiers. A number is added only when the name and the tier both match.
- **Why:** D-223 "Two pieces with the same name" (Crown), replacing Q-516's number-only default.
- **How it was checked:** build and the full suite; wor-reviewer.
- **Known limit:** a ring's tier is its own until stage 2b builds the ring-and-crystal average.
- **For Crown:** `docs/PIE/B-516.md` checks 11-13.
