# PIE — B-571: the trial pool, stage 7: the merchant's shelf (D-225, TrialPoolDesign §2)

**Branch:** `feature/B-571-trial-merchant` (built and tested on the desktop 2026-11-18). **Built unseen:** not played yet.

**What it is:** a vendor met in a trial now shows 8 lines: 4 from its own list (things that never drop) and 4 from the trial's pool (what chests and enemies can give, sold instead).
- Its own lines come first, then the pool's.
- If one side has too few lines, the other fills the places. A trial with no pool shows the vendor's own list, as before.
- A pool line the vendor already lists itself isn't shown twice.
- The same run shows the same shelf; a new run rolls another. Home shops are unchanged (the full list).

**Defaults chosen (Crown may change, Q-571):** the pool half is the trial's own pool tag, not the zone the vendor stands in; a pool piece is sold at its own tier and price like any stock line; any vendor type may show any pool kind.

**Editor steps:** none.
