# PIE — B-620: weapon buffs can't be infused

**Branch:** `feature/B-620-weapon-buffs-no-infusion` (built 2026-11-25 on `feature/B-613-sticky-infusion`; merge B-613 first).
**What it is:** Crown's rule (D-275): "weapon buffs cannot be infused with elements". A weapon ability with no damage aimed at yourself or an ally (a buff like Rally) shows no infusion line, and using it doesn't turn off the infusion you keep for strikes (B-613).
**Already proven by tests:** `WoR.UI.CommandMenu.Keys` (a weapon buff opens at no infusion, no level can be picked, using it keeps Lv I on; which skills count as a weapon buff; the dropped infusion) and the full suite plus validation on the final tree: 2610 passed, 0 failed; validation 0 new.
**Not proven:** in game. No weapon buff exists yet (Rally is coming); until then, set any weapon ability's Base Damage to 0 and Target Type to Self or Ally (it needs a buff or heal effect) to try it.
**Setup:** a fighter with a damaging weapon skill and a weapon buff (see above), enough EP.
