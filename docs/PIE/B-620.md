# PIE — B-620: weapon buffs and debuffs can't be infused

**Branch:** `feature/B-620-weapon-buffs-no-infusion` (built 2026-11-25 on `feature/B-613-sticky-infusion`; merge B-613 first).
**What it is:** Crown's rule (D-275): "weapon buffs cannot be infused with elements", debuffs too. A weapon ability with no damage and a buff or debuff effect, on anyone (a buff like Rally), shows no infusion line, and using it doesn't turn off the infusion you keep for strikes (B-613).
**Already proven by tests:** `WoR.UI.CommandMenu.Keys` (a weapon buff opens at no infusion, no level can be picked, using it keeps Lv I on; which skills count (a weapon debuff does, a spell buff doesn't); the dropped infusion) and the full suite plus validation on the final tree: 2619 passed, 0 failed; validation 0 new.
**Not proven:** in game. No weapon buff exists yet (Rally is coming); until then, set a weapon ability with a buff or debuff effect to Base Damage 0 to try it.
**Setup:** a fighter with a damaging weapon skill and a weapon buff (see above), enough EP.
