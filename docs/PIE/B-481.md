# PIE — B-481: menu key hints follow the device; Backspace is Back

**Branch:** `feature/B-481-device-key-hints` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.UI.KeyHints` (5 cases: both key sets, Backspace and Esc are Back keys, a caller's value beside key names, a hint text with no player); every screen's own spec stays green.
**Setup:** open the hub with a keyboard and, for checks 2 and 3, a gamepad plugged in. Console `wor.UI.KeyHints.Print` lists every key name on both devices and says which device is in use.

| 2 | Press any gamepad button (a D-pad press) | The same texts switch at once to "A  Edit        X  Simple        Y  Options        B  Back", LT / RT and LB / RB | [ ] |

**Notes / what went wrong:**
- Esc ends PIE in the editor, so use Backspace there; in a built game both work.
- In a fight Backspace is End Turn (B-170e); no menu screen is open there, so the two don't meet.
- Not converted (they don't use the shared menu builders): the old hub windows with clickable buttons and the battle HUD.
