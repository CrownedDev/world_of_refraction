# PIE — B-477: Generic weapon sets, first part (D-209 to D-211)

**Branch:** `feature/B-477-weapon-sets-cloud` (cloud, UNBUILT; branched from `feature/B-472-loadout-costs-cloud`, so B-472 comes with it).
**Already proven by tests (once built):** `WoR.Loadout.WeaponSets`, and the B-472 specs.
**Setup:** build, run the tests. In the editor, open two sword assets and set **Weapon Set → Handling** to *Single or dual* on both (and a dagger the same); leave **Dual Wield Stance** empty on one, set it on the other. In an authored Generic loadout (the character's inventory data), put one sword as the primary weapon and the other as **Primary Off Hand Weapon**. Start PIE in the hub with that Generic.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Run `wor.Loadout.PrintWeaponSets` | The Generic's primary reads "Sword (...) + Sword (...): pair OK", its tier slots the average of the two tiers' (rounded down), its stance the main hand's dual-wield stance (or its own when unset) | [ ] |
| 2 | Run `wor.Loadout.PrintFindings` | No finding for the pair | [ ] |
| 3 | Start a fight, open the Abilities menu | One list: both swords' built-in abilities are there, the main hand's first | [ ] |
| 4 | Look at the character's idle stance in the fight | The main hand's dual-wield stance (when set) | [ ] |
| 5 | `wor.Stats.Print` (or the character sheet) | Both swords' stat lines are added (e.g. two Defence lines) | [ ] |
| 6 | Swap the order (the other sword as the main hand), restart PIE, `wor.Loadout.PrintWeaponSets` | The stance follows the new main hand | [ ] |
| 7 | Put the dagger as the off hand instead, restart PIE | On the fight start a "Removed: Off-hand weapon ... can't pair" message; the sword stands alone | [ ] |
| 8 | Set a sword's Handling to *Dual only* and equip it alone as the primary | On the fight start it is removed and the primary refilled (D-116) | [ ] |
| 9 | Save in the hub with a pair equipped, quit, Continue | The pair is still there (save v39); an older save is wiped with the warning (D-138) | [ ] |

**Not in this part:** the off hand's mesh in the left hand and the AI's sets (B-477b); the screen to build a set (B-476); the asset changes (B-478).
