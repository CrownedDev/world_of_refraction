# PIE — B-526: a dropped skill hits softer (stage S3d)

**Branch:** `feature/B-526-skill-copy-tier` (in dev, built and tested on the desktop 2026-11-16).

**What it is:** D-224 (question 12): a skill's power reads the tier of the character's own learned copy, not the skill asset's. So when a lost run drops a slotted skill 3 tiers (B-525), it hits softer, as dropped gear does: a C skill dropped to F goes from C's tier power to F's (about half its damage). The code already landed with B-519 (its part 5); this job adds the test that proves it. A skill the user doesn't own (an enemy's) still reads its asset's tier.

**Already proven by tests:** `WoR.Combat.SkillCopyTier` (a spell copy and an ability copy dropped from C to F hit softer, by F's tier power over C's; a fresh copy hits as the asset does). Full suite in the session note.

**Not proven by the test:** status build-up reads the same copy tier (same resolver), but no test checks it.
