# PIE — B-366c: shops charge the currency of the place (D-002 notes, ER-21)

**Branch:** `feature/B-366c-shop-place-currency` (in `dev`; built on the desktop 2026-11-04).
**Already proven by tests:** `WoR.Economy.RoundTrip` (a hub purchase spends the hub balance only and the run balance can't pay it; a run purchase spends the run balance only; short by one is refused and spends nothing).
