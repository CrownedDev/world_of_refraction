# PIE — B-440e: loadout screen, saved loadouts

**Branch:** `feature/B-440e-saved-loadouts-cloud` (cloud, UNBUILT: build first).
**Already proven by tests:** `WoR.UI.LoadoutSaved` (6 cases), once the desktop has run it; `WoR.UI.LoadoutScreen` must stay green.
**Setup:** build, open the hub, open the game menu's Loadout page (or console `wor.UI.Loadout`). Console `wor.UI.LoadoutSaved.Print` lists each member's saved loadouts.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Press Y (gamepad) or R (keyboard) on the Gear page | A list over the page: "Saved loadouts (N of 5 of your own):", one line per saved loadout with ACTIVE on the one in use, then "New loadout" | [ ] |
| 2 | Light "New loadout", press A | A new line "Loadout 1" (or the next free number) appears and is lit | [ ] |
| 3 | On it press Y, type "Bruiser", press Enter | The line reads "Bruiser"; the keys work on the list again | [ ] |
| 4 | Press Y again, then Esc | The name box closes; the name is unchanged | [ ] |
| 5 | Press X on "Bruiser" | "Bruiser copy" appears below and is lit | [ ] |
| 6 | Press A on another loadout | The list closes; the page shows that loadout, its name in the top right box | [ ] |
| 7 | Make loadouts until you have 5 of your own | The "New loadout" line goes; X on one says you keep at most 5 | [ ] |
| 8 | If the character has a lore loadout: Y on it, any name, Enter | Refused: it keeps its name; X still copies it | [ ] |
| 9 | With the list open, press LB / RB, LT / RT and Left / Right | Nothing changes until B closes the list | [ ] |
