# PIE — B-440e: loadout v2, saved loadouts

**Branch:** `feature/B-440e-saved-loadouts-v2` (in dev, built 2026-11-14; the cloud branch's list moved from the old screen's Y to the v2 screen's Options).
**Already proven by tests:** `WoR.UI.LoadoutSaved` (6 cases: the list, use, new, duplicate, rename, the v2 screen with no party); `WoR.UI.LoadoutV2Screen` stays green.
**Setup:** open the hub, console `wor.UI.LoadoutV2` (today's `wor.UI.Loadout` is untouched and has no saved list). Console `wor.UI.LoadoutSaved.Print` lists each member's saved loadouts.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Look at the top right | The loadout's name, then "Cells used n of n" | [ ] |
| 2 | Press Y (keyboard R), light "Saved loadouts", press A | "Saved loadouts (N of 5 of your own)": one line per saved loadout, "Active" beside the one in use (it is lit), then "New loadout" | [ ] |
| 3 | Light "New loadout", press A | A new line "Loadout 1" (or the next free number) appears and is lit | [ ] |
| 4 | On it press Y (R), type "Bruiser", press Enter | The line reads "Bruiser"; the keys work on the list again | [ ] |
| 5 | Press Y again, then Esc | The name box closes, the name is unchanged, and **the saved list is still open** (if Esc also went back to Options, note it) | [ ] |
| 6 | Press X on "Bruiser" | "Bruiser copy" appears and is lit | [ ] |
| 7 | Press A on a loadout that isn't active | Back on the entries, now that loadout's; "<name> is now in use."; its name top right | [ ] |
| 8 | Make loadouts until you have 5 of your own | The "New loadout" line goes; X on one says you keep at most 5 | [ ] |
| 9 | If the character has a lore loadout: Y on it, any name, Enter | Refused: it keeps its name; X still copies it | [ ] |
| 10 | In the saved list press B | Back in Options, on "Saved loadouts"; B again closes Options | [ ] |
| 11 | With the name box open, press LT / RT, Up / Down | Nothing moves until Enter or Esc | [ ] |
