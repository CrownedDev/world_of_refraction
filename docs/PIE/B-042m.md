# PIE — B-042m: Ignore Defense as an amount (D-086)

**Branch:** `feature/B-042m-ignore-defense-amount` (merged into `dev`).
**Already proven by tests:** `WoR.Damage.IgnoreDefense` (4 cases) checks:
- 0% keeps the full Defense, 50% halves it, 100% removes it (the same damage as the old full ignore);
- the same share cuts a positive element resistance, and a weakness stays;
- a skill's amount and Ignore Defense effects add up, capped at 100%;
- an Ignore Defense effect with no value still ignores all Defense.

The full suite (690) is green.

What changed:
- Every skill (ability, spell, attack) has a new **Ignore Defense %** field in the Details panel, Combat section. It defaults to 0, so no skill changes until you set it.
- An Ignore Defense effect now ignores its own value (its text already says "ignore N Defense"). One with no value still ignores everything.

**Setup:** pull `dev`, build, **restart the editor** (a new field), start the demo fight.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Open a skill asset (an ability or spell) | A new **Ignore Defense %** field under Combat, 0 | [ ] |
| 2 | Note the damage that skill deals to an enemy with high Defense. Set the field to 50, play again, same target | More damage: half of the Defense cut is gone | [ ] |
| 3 | Set it to 100 | The hit ignores Defense completely | [ ] |
| 4 | If a skill or item grants an Ignore Defense effect with a value (e.g. 30) | Its attacks ignore that share, not all Defense | [ ] |
| 5 | Set the field back to 0 | Damage as before | [ ] |
