# PIE — B-391: the new placeholder battle HUD (Q-391)

**Branch:** `feature/B-391-battle-hud-cloud` (cloud pre-write, UNBUILT, from dev).
**Already proven by tests (once built):** `WoR.UI.BattleHUD`: the turn strip leads with the current actor and numbers the rest on; HP text and fraction; status chips; each menu key goes to the row it presses. Headless on a duel: a party card's HP line follows a hit, the strip leads with the acting character, the status panel names everyone, the command menu lists the buttons with key hints and its Defend row passes the turn. `WoR.UI.CommandMenu.Keys`: the category keys work from the main menu only, press only a button the menu offers, and every key has a unique action and a keyboard key.
**How to open it:** start any fight (a trial fight, or the usual test map). `wor.UI.NewHUD` is 1 by default; set it to 0 before the fight starts to get the old HUD back for comparison.
**Note:** B-396 (old HUD invisible) is still open. If the new HUD is invisible too, `wor.UI.Print` (check 9) shows why, the same way.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Start a fight | Top left: "Turn order", then "> 1  <name>" in gold and the next turns below it (enemies in a reddish tint). Bottom left: one card per party member with name, red HP bar, "HP x / y" and "EP x / y". Top right: one card per enemy with name and HP bar, no numbers. Top centre: a **Statuses** button. Bottom right: the command menu titled "<name>'s turn". No old WBP panels or strip | [ ] |
| 2 | Look at the menu rows | Each main-menu row that has a key starts with it, e.g. "[1 / A] Attack (Longsword)", "[G / Y] Defend"; greyed rows can't be clicked | [ ] |
| 3 | Click **Attack**, then a target | The attack plays; the menu hides during the action and comes back for the next player turn; the turn strip moves on | [ ] |
| 4 | On the main menu press **1** (or **A** on a pad), then pick a target with the mouse | Same as check 3: the key opens the attack's target list | [ ] |
| 5 | Press **2** / **X** (skills) and **3** / **B** (spells) on a character that has them; in a submenu press **1** | 2 / 3 open the skills / spells list; inside a list, 1 does nothing (category keys are main-menu only) | [ ] |
| 6 | Hit an enemy and take a hit | The enemy's bar drops; your card's HP text and bar drop; a downed character's card dims | [ ] |
| 7 | Put a status on someone (a stun, a buff, a burn) | A chip like "Stun 1" appears on that card; it counts down each turn and goes when it ends | [ ] |
| 8 | Click **Statuses**, then click it again | A dark panel in the middle lists every combatant with each status in full (name, element, turns left, stacks, description), or "no statuses"; the second click closes it | [ ] |
| 9 | Type `wor.UI.Print` | The print starts "hud=new (wor.UI.NewHUD 1)", then `battleHUD:` and `battleMenu:` lines (in viewport, visibility, position, size) and the cards, turn strip and menu rows as shown | [ ] |
| 10 | End the fight, then type `wor.UI.NewHUD 0` and start another | The old HUD is built instead (the print says hud=old); set it back to 1 afterwards | [ ] |
| 11 | 2-player PIE (Listen Server): on the client, play a turn | The client has the same HUD: its party, the turn order and the menu on its own turns | [ ] |

**Known:** placeholder looks (plain text, no icons; style pass with CommonUI, D-024). Picking inside a submenu or target list is a mouse click for now. Damage numbers and the Broken Darkness absorption line are B-391b.
