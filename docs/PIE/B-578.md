# PIE — B-578: input works after a fight

**Branch:** `fix/B-578-input-after-fight`.
**What was wrong:** back in the trial after a fight, move, Tab and click did nothing. The results screen left the game in "menu only" input and the next level kept it.
**What changed:** game input is given back when a level change starts with menu-only input still on (`docs/Architecture/GameInput.md`).
**Already proven by tests:** `WoR.Input.LevelChange` (3 tests) and the full suite, headless. Not proven there: a real level change and keyboard focus.
**Written for an agent with `WoRAgentPlayToolset`** (`Conventions/HandsOffPlan.md`, "How an agent plays"); a person can do the same by hand. Play on the QA save folder only.
**The check to read:** `wor.Input.PrintState` prints one line. "game input: on" is right in a level; "game input: IGNORED" is right only while a menu is open.
