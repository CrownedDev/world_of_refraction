# PIE — B-103: CommonUI base layer

**Branch:** `feature/B-103-commonui-base` (in `dev`).

**Already proven:** the editor builds and every test passes. `WoR.UI.Stack` (2 cases) checks:
- Back deactivates the test screen;
- a layer stack takes the test screen and removes it again.

Headless tests can't show a screen, so activation through a stack and the Back key are checked here.

**What changed:** the root layout has Game, Menu and Modal layers with push/pop for each; a button base (`UWoRButtonBase`) with four jobs (Play, Confirm, Danger, Navigate) that pick their style; an empty test screen.

**Setup (editor, once):**
- Root layout WBP (the class on `AWoRHubController.RootLayoutClass`): add a `CommonActivatableWidgetStack` named exactly `ModalLayer`, above `MenuLayer`. Without it, modal pushes go to the menu layer (warning in the log).
- `BP_CommonInputData` (`/Game/UI/Core/`): Enhanced Input support is on (`DefaultGame.ini`), so it needs **Enhanced Input Back Action** set (Esc and gamepad B mapped); otherwise the Default Back Action row is used. If neither is set, Back does nothing.
- PIE in the hub with the hub controller (`AWoRHubController`) and a gamepad plugged in. Output Log open, filter `LogWoRUI`.
