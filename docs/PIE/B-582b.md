# PIE — B-582b: battle menu keys, Enter / Space, W / S, A / D, Q / E (D-267)

**Branch:** `feature/B-582b-confirm-keys`.
**What changed:** in the new battle HUD:
- **W / S** light the row above / below in any battle list, wrapping.
- **Enter / Space** press the lit row. With nothing lit, in a target picker they pick the marked target.
- **Q / E** step to the previous / next target in a target picker; the marker and camera follow.
- **A / D** change the lit row's value (infusion Level; Source steps forward), and on a target row act as Q / E.
- Tab is unchanged (boss-cinematic skip only). None of these keys act while Intel is open or a Guard / Dodge window is open.

**Already proven by tests:** `WoR.UI.CommandMenu.Keys`, both B-582b specs:
- all 8 actions exist and there is no Tab;
- the main menu starts unlit and Enter does nothing; S lights Attack, W wraps to the last row, S wraps back;
- Enter on Attack opens the picker on the foe, Enter again attacks;
- an unlit Position picker ignores Enter; a skill's picker takes Enter;
- E / Q / D / A cycle two foes, wrapping, the lit row following; S onto the other foe's row highlights it.

**Not proven there:** real key presses, which editor-mapped keys Guard / Dodge use, Slate's Accept in a real window, camera movement, a gamepad.

**Written for an agent with `WoRAgentPlayToolset`** (`Conventions/HandsOffPlan.md`). Play on the QA save folder only, at `SetWindowSize(Width=1280, Height=720)`; repeat 1 and 4 at `SetWindowSize(Width=1920, Height=1080)`.
