# PIE — B-582b: Enter and Space confirm in the battle target pickers (D-267)

**Branch:** `feature/B-582b-confirm-keys`.
**What changed:** in the new battle HUD, **Enter** and **Space** pick the highlighted target in a target picker (Attack, a skill, an item), the same as clicking its row or the Attack picker's second 1. They do nothing on the main menu, in the Position picker, on a group pick (Self / All: still a click), while Intel is open, or while a Guard / Dodge window is open.
**Already proven by tests:** `WoR.UI.CommandMenu.Keys` "confirms the highlighted target on Enter / Space": both keys have their own action; nothing on the main menu or in the Position picker; in a skill's picker Enter / Space picks the highlighted foe (and 1 doesn't). The B-582 quick-attack spec still passes on the shared path.
**Not proven there:** real key presses, whether the Dodge key in the editor's context is Space, Slate's Accept in a real window, a gamepad.

**Written for an agent with `WoRAgentPlayToolset`** (`Conventions/HandsOffPlan.md`). Play on the QA save folder only, at `SetWindowSize(Width=1280, Height=720)`; repeat 1 at `SetWindowSize(Width=1920, Height=1080)`.
