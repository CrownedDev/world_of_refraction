# PIE — B-367: interrupt points end the skill on a perfect defense; Flawless Parry at an interrupt (D-161)

**Branch:** `feature/B-367-interrupt-points` (in `dev`; built on the desktop 2026-11-04).
**Already proven by tests:** `WoR.Defense.Guard` (only a Perfect Guard or a Perfect Dodge stops an interrupt point; a normal Guard or Dodge doesn't), `WoR.Defense.FlawlessParry` (a perfect defense ending the attack at an interrupt point with every hit so far perfect reports once; never after an imperfect hit; never twice). No headless test plays a real montage interrupt, so checks 1-3 are PIE-only.
**Setup:** an enemy skill with an interrupt point. A multi-hit ability with a `DamageSplit` entry marked **Interruptable** (say hit 2 of 3), or a spell with a cast entry marked Interruptable. To find one, call `USkillCastDebug::GetInterruptPointsString` on it (`PrintCastArray` prints it too): `Interrupt points (X): hit 2`. For check 3, wear an effect with the trigger **On Flawless Parry** (or watch the log).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Perfect Guard (or Perfect Dodge) every hit up to and including the interrupt point | The skill stops there, the rest doesn't land, and the return montage plays if authored. Log: `[Defense] Flawless Parry at an interrupt point` (once) | [ ] |
| 2 | Same skill: a normal-timing Dodge on the interrupt point | The skill carries on to its end (before B-367 a normal Dodge stopped it) | [ ] |
| 3 | Same skill: a normal Guard on hit 1, then a Perfect Guard on the interrupt point | The skill stops at the interrupt point; no Flawless Parry line | [ ] |
| 4 | An attack with no interrupt point, every hit perfectly defended | One Flawless Parry at the last hit, as before (B-365) | [ ] |
| 5 | A spell with an interrupt cast entry against two party members: both Perfect Guard / Dodge every arrival up to the interrupt point | The spell stops; one Flawless Parry line **per defender** (the first target's window had already closed) | [ ] |
