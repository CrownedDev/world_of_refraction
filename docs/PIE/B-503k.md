# PIE — B-503k: the field attack strip, LB changes the infusion (D-217)

**Branch:** `feature/B-503k-field-attack-strip` (in dev, built and tested on the desktop 2026-11-15).
**What it is:** D-217, from Crown's PIE of B-503j. The field attack chip is gone. In a trial a small strip directly above the played character's card names the field attack: the weapon type (Sword), the element first when infused (Fire Sword); a Refractor or Resonator just the element (Fire). R / LB steps the **infusion** (plain first for a weapon user, then each element of the character's combat infusion sources), not the weapon. The hub card fits its name. The battle card has no weapon line (Generic Primary Weapon); hovering it still shows the gear tooltip.

**Already proven by tests:** the full suite passes; specs check a weapon user's cycle (plain Sword, then Fire Sword from its weapon's crystal, then back; the strike follows the stop), a Refractor's cycle (Water, then Fire, pulses named by the element, no plain stop), the swing montage on the infused stop, which card gets the strip (skipping a member with no data), the strip in a trial only, the hub card's fitted width and the battle card's gear tooltip with no line.
**Not proven:** nothing seen in PIE.

**Decided by default (Q-503k, Crown may change):** only the played character's card has the strip; one stop per element (two Fire sources are one stop); a Refractor's weapon crystal is a stop; an unarmed weapon user shows no strip until infused. **Press and hold (Crown, D-217):** a press of R / LB changes the source, a hold (0.4 s) the element within it; every source has one element today, so a hold changes nothing. Broken Darkness and Reality on a hold wait on Crown (Q-503l, B-503l).
