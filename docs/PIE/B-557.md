# PIE — B-557: the hub's recruits are Spirits, built like the player (one-player stage 4b, first half)

**Branch:** `feature/B-557-recruit-spirits` (in dev, built and tested on the desktop 2026-11-17). **Built unseen** (overnight run): nobody has looked at it in PIE yet.

**What it is (D-238):** each of the 12 walk-up recruits is now the shared player character built from a row of fixed picks on the class table, not its old Lord asset:
- Each is named by its element or class: Generic Spirit, Resonator Spirit, Fire Spirit and so on, and Broken Darkness Spirit.
- Its class, element, numbers, innate spells and starting gear come from the class table and its picks, the same way as the player's (stages 3 and 4).
- The Generic Spirit's picks are Sword and Shield. The Resonator Spirit's are Garnet and Sapphire.
- A trial lays its picks over its class kit, as for the player.
- It fresh-starts (D-238): none of the old Lord's evolutions, rings or gear.

A placed recruit finds its row by its old asset's class and element, so the 12 placed actors need no change. A class or element with no row stays its old Lord. A Lord already in the party from an older save stays itself (it can still be dismissed).

**Not in this half (B-558):** a recruit wearing spirits from the Spirit screen, and the element or class colour on the body. A recruit keeps its Blueprint's look for now.

**Editor steps first (the editor session):**
1. Open `/Game/Data/Loadout/DA_Loadout_ClassDefaults`. Under **Recruits**, click **Fill Recruits**. Twelve rows appear.
2. On each row, set **Body** (the Starting spirit) to the body that recruit's Blueprint has today: Manny is **Male Nobody**, Quinn is **Female Nobody**. Every row starts on Male Nobody. List which of the 12 are Quinn. Rename a row's Name if wanted. Save the asset.
3. Click **Print Defaults** (Debug). The end lists `Recruits: 12`, one line each with class, element and body.
