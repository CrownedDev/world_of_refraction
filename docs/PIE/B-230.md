**Branch:** `feature/B-230-replicated-status-bars-cloud` (cloud pre-write, UNBUILT: build and run the specs first). For a client HUD to exist at all, merge B-228b first (or test both together).
**Already proven by tests (once built):** `WoR.Combat.StatusBarState`: the component copies its owner's bar from the buildup manager, and only its owner's.
**Setup:** 2-player PIE (Listen Server), a fight with elemental attacks.
