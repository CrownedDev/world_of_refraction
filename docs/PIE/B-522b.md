# PIE — B-522b: prebuilt finds (asset overhaul §3 "Found pieces", Crown Q7)

**Branch:** `feature/B-522b-prebuilt-finds` (in dev, built and tested on the desktop 2026-11-16).

**What it is:** a found piece may come built. A plain weapon or ring in a loot pool still arrives empty (B-521). A new data asset, **Prebuilt Find** (`UPrebuiltFindData`), names:
- `Piece`: a weapon or an adapter ring;
- `SourceTags`: the loot pools it rolls in (like a plain asset's);
- `Crystal`: a gem for the socket, at full durability; **or**
- `Evolution`: an evolution for the socket, made the finder's own, so it can be taken off and used elsewhere.

A chest's roll picks it like any plain asset. The message names the socket: "Found Adapter Ring with Phoenix Fire."

**Already proven by tests:** `WoR.Trial.PrebuiltFind` (a ring with its evolution in the socket and owned; a weapon with its gem socketed and none loose; a plain ring empty; a find with no piece refused; the pool roll and the name). `WoR.Packaging.CookRules` (the new type is always cooked). Full suite 2259 passed, 0 failed; validation 16 known, 0 new.

**Not proven:** a real chest in PIE, and the Equipment screen showing the built piece.

**Known limits:**
- A full gem pouch or a full evolution count (5) leaves the socket empty: the piece still arrives, and a warning is logged.
- Enemy drops don't give gear yet; this is for chests (and anything else that calls `TrialLoot::GrantTo`).
- A merchant's stock stays empty (plan §3).

## Editor step (before the checks): one prebuilt find

The editor worker:
- Create `Content/Data/Loot/DA_Find_Ring_PhoenixFire` (class **Prebuilt Find Data**): `Piece` = `DA_Ring_Adapter`, `Evolution` = Phoenix Fire (stage 5; until it exists, use Gale Force), `SourceTags` = the first trial zone's loot pool (the tag on its `EnemyZone`'s `Loot Pool`, e.g. `Source.Zone.Tier1`).
- Optional second one: `DA_Find_Ring_Garnet`: the same ring, `Crystal` = Garnet F.
- To make the chest give it for the check, set one chest's own `Loot Pool` to a tag only the find carries (or run `wor.Trial.Pool <tag>` to see what the pool holds).
