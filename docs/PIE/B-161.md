# PIE — B-161: editor loadout check uses the character's authored stats

**Branch:** `feature/B-161-editor-discount-authored-stats` (in `dev`).
**Already proven:**
- The editor builds and every test passes. A new `WoR.Loadout.Rules` case checks that four S-tier innate spells:
  - are over the innate budget when no character is attached
  - fit for a character whose authored Mind, Body and Spirit all reach the discount thresholds (4 / 7 / 5)

**What changed (D-080 = D):**
- A character's **Validate** now weighs its inventory's loadout spells with the discount from that character's authored world levels (`WorldMindLevel` / `WorldBodyLevel` / `WorldSpiritLevel`). So a high-stat boss can carry what its stats allow.
- An inventory asset validated on its own (no character) still uses no discount, the strictest budget.
- The load-time validation log in PIE uses the same authored discount.
- In a fight nothing changes: the fight already uses the character's live world stats.

**Setup:** open the editor on `dev` and open the Output Log.
