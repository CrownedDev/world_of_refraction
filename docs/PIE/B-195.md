# PIE — B-195: hub services as V

**Branch:** `feature/B-195-hub-services` (in `dev`).

**Already proven:** the editor builds and every test passes. `WoR.Hub.Services` (2 cases) checks:
- with only a Blacksmith placed, the check names the missing services, the Stone Smith and loadout vendor included;
- with one NPC per service, nothing is missing.

**What changed:**
- Two new merchant types: **Stone Smith** (augment stones) and **Loadout Vendor** (the purchase loadout).
- Merchant Data has a **V Outfit Mesh** slot. When it is set, that service's NPC shows the mesh instead of the cube.
- `wor.Hub.Services` lists every service NPC in the level and the services that have none.
- Every NPC opens the shop window. Upgrade, repair and merge screens come later.

**Setup:**
- Create two Merchant Data assets: Merchant Type **Stone Smith** (stock: a few augment stones) and **Loadout Vendor** (stock: a weapon or two).
- Place a Merchant Interactable for each in the hub and assign the assets.
- The hub should already hold the five stocked merchants (Blacksmith, Jeweler, Combat Master, Spell Shop, Spiritualist); place any that are missing, so there are seven NPCs.
- Optional: set **V Outfit Mesh** on one of the merchants to any mesh (for example a cone).
- Output Log open.
