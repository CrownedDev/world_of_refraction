# PIE — B-114: the AI judges status buildup by the real number

**Branch:** `fix/B-114-ai-buildup-estimate` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.AI.BuildupEstimate` (2 cases) checks that the AI's estimate for a 3-hit ability and a 3-hit spell equals what the real hit adds to a status bar.

**What changed:** when picking moves, the AI got status buildup wrong in two ways:
- For abilities, it used a flat 5 per hit instead of the skill's own buildup.
- For multi-hit spells and abilities, it counted the whole buildup once per hit.

It now uses the same number the hit actually adds. In play, an enemy picks "fill the status bar" moves based on real numbers.

**Setup:** a fight against an enemy on Medium difficulty or higher that has an ability with status buildup. Output Log open.
