# PIE — B-010: one random seed per battle

**Branch:** `feature/B-010-battle-random-stream` (in `dev`).
**Already proven:**
- The editor builds, and 42/42 tests pass.
- The new `WoR.Combat.BattleRandom` tests show that the same seed gives the same rolls, and that over 24 hits with a 50% crit chance the same hits crit for the same damage.
- Two fights started on the same seed roll the same crits.
- `wor.Battle.Seed` forces the seed, and starting combat sets it.

**What changed for the player:** nothing you should notice. Every random roll in a fight comes from one stream that starts from a seed. Those rolls are:
- crits
- Broken Darkness
- AI choices and defense
- random targets and random debuffs
- luck skips
- the Amethyst gamble

The seed is written to the Output Log when the fight starts, so a fight can be played again with the same rolls. Rolls outside a fight are unchanged: gear substats and loot quality.
**Setup:** open the editor on `dev`, open the Output Log, and have a fight ready to start. An all-AI or Easy fight shows the replay best.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Start a fight | The Output Log shows `[BattleRandom] Battle seed N (replay with: wor.Battle.Seed N)`. Fights play as before: crits, AI picks and defenses still vary | [ ] |
| 2 | During the fight, type `wor.Battle.PrintRandom` in the console | On screen and in the log: the seed, how many rolls so far, and the replay command | [ ] |
| 3 | Start another fight | A different seed from step 1 | [ ] |
| 4 | Type `wor.Battle.Seed 12345`, then start a fight and play a few turns doing exactly the same things. Stop PIE, start PIE again, and repeat the same fight with the same actions and timing | Both runs log `Battle seed 12345 (from wor.Battle.Seed)`. AI picks and crits come out the same as long as your own actions and defense timing were the same | [ ] |
| 5 | Type `wor.Battle.Seed 0` and start a fight | A fresh seed again, not 12345 | [ ] |

**Note:** a replay matches only when your inputs match. Your own choices and how well you time a defense change what comes next. The seed also only replays on the same build, because a roll added to the code shifts the later ones.
