# PIE — B-154: Delete URingManager and UWeaponManager

**Branch:** `feature/B-154-ring-weapon-managers-delete-cloud` (cloud pre-write, UNBUILT, from `dev`). A deletion: **merge only after Crown's PIE of B-024** (CLAUDE.md: no deleting code before it's verified in PIE).

**What was deleted (Blueprint-visible):**

- `UActionExecutor::GetRingManager` (BlueprintCallable, "Action Executor|Utility"); `GetWeaponManager` and the two cached-ref UPROPERTYs were C++ only.

No CoreRedirects: a Blueprint node that still calls one of these breaks when this branch is built, so check first. The replacements are on the Loadout Component: `GetActiveRing`, `GetActiveRingElement`, `GetPrimaryRing`, `SwitchToNextUsableRing`, `GetActiveWeapon`, `GetCurrentAttack`.
