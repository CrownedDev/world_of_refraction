# PIE — B-042k: GAS stage 3, part 4b (every effect type on GAS)

**Branch:** `feature/B-042k-gas-remaining-families` (merged into `dev`).
**Already proven by tests:**
- `WoR.GAS.EffectBuilder` checks that every effect type but None has a GAS class.
- `WoR.GAS.EffectMirror` holds one effect of every type and checks that the GAS copy matches.
- It also checks that "does it have this effect?" and "how big is it?" read the same with `wor.Effects.UseGAS` at 0 and at 1.
- The full suite (675) is green.

What changed:
- Reflects, Last Stand, lifesteal and the other on-hit extras, guaranteed crits, random skill, restores, drains, cleanses and pushes now have a GAS form.
- The GAS copy covers every effect, so with the switch at 1 the game reads all of them from GAS.
- Today's system still does what the effects do.
