# PIE — B-525: a run's slotted skills are kept, like worn gear (stage S3c)

**Branch:** `feature/B-525-settle-run-skills` (in dev, built and tested on the desktop 2026-11-16).

**What it is:** D-224 ("found skills follow the equipment rules", questions 10 to 12) with D-219. When a run ends, only the skills **slotted** at that moment (in a slot of a worn weapon or adapter) count:
- **A finish or an extract:** a slotted skill found in the run joins the hub list. Anything only in the list goes back.
- **Out of wipes:** the same, and every slotted skill (found or owned) drops 3 tiers, never below F, as worn gear does.
- **A quit (or the game closed mid-run):** skills found in the run are lost. The owned skills that were slotted drop 3 tiers.

The next trial still starts with no skills (B-523). A kept skill is for the hub and its presets. Choices taken: Q-525.

**Already proven by tests:** `WoR.Run.Skills` (one case per ending: extract, out of wipes, quit; the innate spell is not touched). Full suite in the session note.

**Note:** a skill's power still reads the skill's own tier until B-526. So after a lost run the dropped tier shows in the skill's details, but the hit doesn't get softer yet.
