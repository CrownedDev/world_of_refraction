**The Emerald as an item after socketing (Crown, 2026-11-25):** a spec (`WoR.Loadout.SocketedCrystalItem`) shows a crystal socketed from the loadout leaves the pouch and the fight's items, and a loose one stays. It comes back as an item only when it sat in a **class kit** piece and a trial start reset the kit (D-221: the kit's sockets go back to the pouch). If you see it again: in the hub, `wor.Trial.PrintClassDefaults` (is that Hand Axe a kit piece?) and `wor.Pool.Print` (how many Emeralds the pouch holds). Note both lines here.

**Known, by design (not this fix):** the fight's item list offers crystals ("Emerald (S) x1") because D-133 makes a gem a fight item (the Emerald a bonus turn). A trial start puts every member back on the class kit (D-221), so a tier set in the hub does not carry into a trial (B-615 looks at the Caster's ring).
