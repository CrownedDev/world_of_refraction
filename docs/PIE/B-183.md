# PIE — B-183: the trial door asks for a variation and a difficulty

**Branch:** `feature/B-183-gate-choice` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Trial.Gate` (4 cases) checks four things: each harder level pays more and makes enemies stronger, with Medium unchanged; the run keeps the choice; an enemy gets the level's max HP and starts full; a cleanse can't strip it.

**What changed:** walking into a trial door now opens a plain panel (a placeholder until the real screen). It has the trial name, a variation button (only when the trial has variations), a difficulty button that cycles Easy, Medium, Hard, then Enter and Cancel. On Hard every enemy has 25% more max HP and deals 25% more damage; on Easy 20% less. The payout multiplier is stored but nothing pays out yet (B-073). The return door works as before.

**Setup:** the hub with a trial door. Optionally, give that trial's data asset two entries under **Gate > Variations** (a name and a description each). Output Log open.

|---|---|---|---|
| 1 | Walk to the trial door and interact | The gate panel opens with the trial name and "Difficulty: Medium (enemies x1, payout x1)"; the mouse cursor shows | [ ] |
