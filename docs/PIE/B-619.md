# PIE — B-619: element tint for the SoftTofu effects

**Branch:** `feature/B-619-softtofu-color-tint` (built 2026-11-25 from dev 4d451b497).
**What it is:** the SoftTofu effect packs take their colour from one setting (`Color_`), which our code never set, so an infused Force Strike's air slash stayed pale. Now an element-coloured projectile or skill effect sets it to the element colour. A plain (uninfused) one is left as the pack draws it (D-273).
**Already proven by tests:** `WoR.Presentation.EffectTint` (Fire and Wind set it, None and Generic don't; the value lands on the `User.Color_` vector) and the full suite plus validation on the final tree: 2618 passed, 0 failed; validation 0 new.
**Not proven:** the colour in game. If a pack's `Color_` is a colour rather than a vector, it stays pale: tell the Code Writer.
**Setup:** a fighter with Force Strike (it uses a SoftTofu air slash) and a crystal or innate element to infuse with.

|---|---|---|---|
| 1 | Use Force Strike with no infusion | The pale air slash, as before | [ ] |
