# PIE — B-279c: outfits

**Branch:** `feature/B-279c-outfits` (in `dev`; written in a cloud session, built and tested on the desktop).
**Already proven by tests:** `WoR.Character.Outfit` (a swap replaces only its slot; a set saves and loads; a skin brings its authored outfit; swaps only where skins switch). `WoR.Character.FormSkins`, `WoR.Save.*` still green (save v10).

What changed for play: the data and assembly for **six outfit slots** (Helmet, Jacket, Shirt, Waist, Trousers, Footwear). No piece exists yet: authoring them is editor work (one `UOutfitPieceData` asset per piece, its mesh skinned to the shared body). Until then nothing changes on screen.

**Setup:** pull the branch, build. In the editor, create two `OutfitPieceData` assets (e.g. a Jacket and Footwear) pointing at any skeletal meshes skinned to Manny, and give a test form an authored outfit with the Jacket.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Open an `OutfitPieceData` asset, press **Print Piece** | Its slot, mesh, material and colour keys in the Output Log | [ ] |
| 2 | Start PIE in the hub, wear the test form (`wor.UI.Forms`) | The form's mesh plus the authored Jacket on top, moving with the body; `wor.Outfit.Print` lists it | [ ] |
| 3 | At the hub: `wor.Outfit.Wear /Game/<path>/<Footwear piece>`, then `wor.Outfit.Clear Jacket` | Boots appear; the Jacket goes, the rest stays. In a fight or away from a rest spot both are refused | [ ] |
| 4 | Stop PIE, start again | The same skin and outfit (save v10) | [ ] |
| 5 | Take the skin off | The base body (Manny / Quinn) still wears the outfit (Q-279c). **Note:** an outfit on the default look replaces a Blueprint-authored pawn mesh with Manny / Quinn | [ ] |
| 6 | `wor.Outfit.Clear` every slot | Every piece mesh disappears | [ ] |

**Could not be verified in the cloud (no Unreal):** compile, tests, and the look (Leader Pose with real meshes, colour keys on the material). Swapping is reachable through the placeholder console commands `wor.Outfit.Wear` / `wor.Outfit.Clear` until the wardrobe screen (CommonUI, D-024). A piece on another skeleton than the body logs a warning.
