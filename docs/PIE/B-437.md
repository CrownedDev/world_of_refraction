# PIE — B-437: the Ability Stone is removed (D-175)

**Branch:** `feature/B-437-remove-ability-stone` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.Loadout.SkillSlotList`: no stone kind adds an ability slot; an S weapon with an S gem and a stone has 12 slots; a pick in a weapon's second slot still reaches the loadout's ability list. `WoR.Currency.SevenBalances`: a stone is paid in Pillar essence, never Skill. `WoR.Save`: a save one version back is wiped with a warning. Full suite: 1907 passed, 0 failed; data validation: no new errors (the five merchant lines below are listed as known debt).
**What changed:** the Ability Stone no longer exists. A weapon's ability slots are its tier's (F 1 … S 6) plus its crystal's, 12 at most; no stone adds any. The separate "stone abilities" list is gone from weapons, loadouts, the save file and the battle menu. The save version is now 38, so **an older save is wiped on first load** (Q-437: no refund for stones you held).
**Needs the editor (B-437b, not done here: the editor was closed):** the five merchants (`Content/Data/Pool/Merchant/`) each still have an Ability Stone stock line; it now loads as an empty line. Any weapon asset with an Ability Stone attached loads with an empty stone type. Both need deleting or re-picking in the editor.
**Setup:** pull `dev`, close and reopen the editor (new enum, new save version).
