# PIE — B-166: montage-less skill start

**Branch:** `fix/B-166-headless-skill-start` (in `dev`).
**Already proven:**
- The editor builds and every test passes.
- `WoR.Combat.RitualFire` now fires a ritual **ability with no montage** on its Execution turn, and a ritual ability whose target is **dead** when it fires (it fizzles without a crash); both times the fight moves on to a normal turn.

**What changed:**
- When a skill fails or finishes inside its own start (no living target, not enough energy, infusion refused), the executor used to read an already-cleared action record to set its timeout, which asserts. It now stops there; the turn ends as before.
- Nothing else changes in play. A skill with a montage takes the same path as before.
- Worth knowing: an ability with **no montage** waits up to 8 seconds before it resolves (the defense window's failsafe), because no hit notifies arrive to close the window. This is today's behaviour, not new.

**Setup:** open the editor on `dev`, open the Output Log, and start a test fight from the trial level.
