# PIE — B-264: a quiet Output Log in fights (P7)

**Branch:** `chore/B-264-log-levels` (merged into `dev`).
**Already proven by tests:** build and the full suite (987 green). Only log verbosity changed.

**Setup:** pull `dev`, build. Any fight; Output Log open.
