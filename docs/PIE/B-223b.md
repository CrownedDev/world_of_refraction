# PIE — B-223b: level drops per character

**Branch:** `feature/B-223b-personal-level-drops` (in `dev`; written in a cloud session, built and tested on the desktop).
**Already proven by tests (full suite green):** `WoR.Trial.LevelDrops` (each case's levels belong to the member that places them; a character's levels go only to its own pillars).

What changed for play: after a won fight in a run, **each party member** rolls its own pillar-level drop, and a mini-boss or boss gives **each member** its levels. In `wor.UI.LevelDrop` each character places only its own levels.
