# PIE — B-469: the new game screen

**Branch:** `feature/B-469-new-game-screen` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.UI.NewGame` (4 cases): the panel title and Begin button follow the pick ("Darkness Refractor", "Begin as a Generic"), each class line ends with its budget, every element has its line; the pick finds its character (class, and a Refractor's element; never the born Broken Darkness lord; none set up says so); the keys (body, class cards, the element grid, Begin); a fresh game in place leaves only the picked character in the party and empties the pool, counters and run.
**What changed:** the title's **New Game** now opens **the new game screen** (with no save; or after the 2-second hold has deleted the save, instead of "begins next time"). Body (Manny / Quinn), Class (Generic, Refractor, Resonator with one line and budget), and for a Refractor the nine elements in the side panel; the panel and the Begin button follow the pick. **Begin** starts the new game at once: everything the old game held is reset, you are the picked lord (the existing lord characters), and the hub opens. Your pawn in the hub and trials now takes the party leader's character. Decisions: **Q-469** (reference-backed default).
**Not checked by me (needs your eyes):** the look against the mockup; that the hub after Begin has the old gold, journal and gear gone; that your pawn walks as the picked class (field moves, element); that the hub's game mode is the trial one (if the pawn keeps its old class, say so: the hub uses another game mode).
**Also for old saves:** your pawn in the hub and trials now always takes the party's first member's character (the leader). For a save made before this, that is the same character the pawn already had; say if Continue shows a different one.
**Left out (noted for later):** the body previews (grey "preview" boxes; an editor step), the mouse, the heading and the opening scene (yours: "placeholder heading" stays).

**Setup:** pull `dev`, build. Play in the hub; open the title with `wor.UI.Title` (or the screen alone with `wor.UI.NewGame`). Begin replaces your save: copy `Saved/SaveGames` first if you want it back.
