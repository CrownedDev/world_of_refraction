# PIE — B-503h: the field attack chip beside the party strip

**Branch:** `feature/B-503h-field-attack-chip` (in dev, built and tested on the desktop 2026-11-15).
**What it is:** the field attack's current loadout entry (icon, name and element) is now always shown at the end of the party strip (B-503g), bottom left, on the hub and trial maps. Pressing R / LB to cycle it lights the chip's panel for a moment, instead of B-503's 2 s popup.
It is shown once the character has field movement, and it keeps up with the loadout within a second (it is read once a second).

**Already proven by tests:** the full suite passes. The chip itself is a widget; only PIE shows it.
**Not proven:** nothing seen in PIE; the flash length (0.35 s) and the chip's size are first guesses.

## Editor steps

None. Pull dev on the main checkout and build with the editor closed.
