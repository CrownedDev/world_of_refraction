# PIE — B-503g: the mockup party strip on the hub and trial maps

**Branch:** `feature/B-503g-trial-hud-party-strip` (in dev, built and tested on the desktop 2026-11-15).
**What it is:** the trial map showed the old debug party box (class, M:1 B:7 S:1, HP and EP bars). The hub and the trial maps share one controller, so they share one HUD. That HUD now draws the party strip from the mockup (`docs/Design/screen_mockups/hub/hud/1_hub_hud_prompt.png`), bottom left: one card per member, each an element dot, the name and an HP bar. The interact prompt and the money chip were already there (B-443).
The old box is hidden. Console `wor.UI.DebugPartyBox 1` shows it again, `0` hides it.
**Not in it:** the field attack chip beside the strip is B-503h, next.

**Already proven by tests:** the full suite passes; the spec checks one card per member in party order, the name, a Caster's element colour on the dot, a non-Caster's generic colour, carried HP over max, and a hub member reading full.
**Not proven:** nothing seen in PIE; the sizes are the mockup's scaled to 1080p and may want tuning.

None. Pull dev on the main checkout and build with the editor closed.
