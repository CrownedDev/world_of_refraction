# PIE — B-471d: characters to talk to in the hub

**Branch:** `feature/B-471d-hub-characters-cloud` (from B-471c's branch; cloud, UNBUILT: build first).
**Already proven by tests:** `WoR.UI.NpcTalk` ("gives a hub character its name and its own conversations"), once the desktop has run it.
**Editor step first:** in the hub map, place an `AHubCharacterSpot` per character to talk to (Place Actors, search "Hub Character Spot"); set its **Character** to the character's data asset; give it the character's mesh if you like (it is a cube by default). A story asset (`UStoryLinesData`) needs a conversation with that character in its **Speakers** (unlocked: its required memories found).
