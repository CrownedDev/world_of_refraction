# PIE — B-327: the zone scales no stats; enemy HP = own x rank x Combat Tier (D-120)

**Branch:** `fix/B-327-zone-health-once` (in `dev`; written in a cloud session, the rule applied and built on the desktop).
**Already proven by tests:** `WoR.Trial.ZoneHealthOnce` (a zone-4 C boss has base x rank x tier HP), `WoR.Trial.EnemyZone` (two zones found; enemies in both end alike, scaled by the door alone), `WoR.Tuning.Baseline`, `WoR.Trial.*`; full suite green.
