# PIE — B-429: a refused item no longer costs an action

**Branch:** `fix/B-429-refused-item-validate` (in dev, built 2026-11-14; written by the cloud, built and tested on the desktop).
**Already proven by tests:** `WoR.Pool.PouchItemUse`: an item the pouch holds is valid; one it doesn't hold is refused at validation. The orchestrator pays the action cost only after validation passes, so a refused item spends nothing.
**What changed:** the item menu only lists what the pouch holds, so the refusal can't normally be reached by hand. The check here is that items still work.
**Setup:** any fight, a character with an item in its pouch. For the action count: `wor.Turns.ActionPips 1`.
