# PIE — B-626: the infusion look depends on its source

**Branch:** `feature/B-626-infusion-looks-by-source` (built 2026-11-25).
**What it is:** Crown: "if infusing a weapon with weapon crystal it uses the weapon infusion if it uses innate character infsuion if its a ring ring infusion and when they stack each one is activated" (D-277). The kept infusion now shows a look by where it comes from:
- a weapon crystal glows on the weapon;
- a ring (adapter) burns as a flame on its finger. The first ring in the loadout goes on the right index finger, then middle, ring, little (Q-626);
- Innate, Evolution and Raw show a body aura.

Stacked same-element sources each show their own look at once. The look stays while the kept infusion is on. These are defaults only; a picker for each kind's look is a later job (B-626b).

**Already proven by tests:** `WoR.Presentation.InfusionLook` covers each source's kind, ring order to finger (weapons and empty slots skipped), and a stack showing each kind once. It also checks that a Fire gem with a Fire innate shows both, and a Water gem with a Fire innate shows the aura alone. The full suite plus validation on the final tree are in the hand-off.

**Until the art is set:** a ring or aura source with no ring flame or aura asset still plays the old glow, as before. A weapon crystal's glow now always sits on the weapon.

## Editor steps (editor worker, before PIE)

1. Open `DA_ImpactVisualDefaults`. Under **Ring Flame Looks**, set a flame Niagara system per element (Element VFX) and a **Default VFX** (used for Raw and any element left empty). Small, finger-sized, for example the Hitman Reborn ring-flame look.
2. Under **Body Aura Looks**, do the same with an aura per element and a default. For example a ground crack plus lightning around the body, Crown's first reference image.
3. Each effect should read a colour parameter for the tint. The code sets the display's colour parameter and, for an element, `User.Color_` (the SoftTofu name).
4. **Ring Finger Sockets** defaults to `index_01_r, middle_01_r, ring_01_r, pinky_01_r`. Check these bones exist on the party's skeleton; rename them in the asset if the skeleton uses other names. A wrong name is safe: the flame sits at the mesh root.
5. Save.

**Known gaps:** a weapon buff or debuff pick hides the look while it's picked (that pick is immune to infusion). A spell's look shows every same-element source, even when the spell's origin rule (B-435b) keeps one out of its damage.
