# PIE — B-300: On Turn Start / End triggers fire every turn

**Branch:** `fix/B-300-turn-triggers-every-turn` (merged into `dev`).
**Already proven by tests:**
- `WoR.Effects.TurnTriggerRepeat`: an On Turn Start trigger fires on two turn starts and spends two charges; a threshold trigger (HP below a line) still fires once per crossing.
- The full suite is green.

What changed (plays differently): an "on turn start" or "on turn end" trigger used to fire only the first time, ever, for the effect's life. Now it fires every turn until its charges run out.

**Setup:** pull `dev`, build. Gear or a skill with an On Turn Start trigger effect (e.g. a heal or EP gain) with 2-3 charges.
