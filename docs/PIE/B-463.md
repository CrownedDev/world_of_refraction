# PIE — B-463: the journal screen

**Branch:** `feature/B-463-journal-screen` (in dev, built 2026-11-14).
**Mockups:** `docs/Design/screen_mockups/menus/journal/1_quests.png`, `2a_secret_quest_hidden.png`, `2b_secret_quest_shown.png`, `3_memories.png`, `4_lore.png`, `5_conversations.png`.
**Already proven by tests:** `WoR.UI.Journal` (9 cases): four named pages, each says so when empty; the selection stays on the talk being played; a quest shows the steps reached and no later one; a secret quest is masked until X shows it, then shows "(found)" and its current step only, and Y hides them all; the filters keep one kind and a secret quest keeps its number; memories list newest first, by character, and count only the found ones; lore lists newest first; a ready conversation plays line by line and is then kept under Played; the screen opens on Quests, wraps its pages and sub-tabs, and hides shown secret quests again when it closes.
**What changed:** the game menu's Journal page opens the new journal screen instead of the old placeholder.
**Not checked by me (needs your eyes):** how it looks, the keys and gamepad, the mouse, long texts.
**Decided by default (Q-463, you may change any):** no "Track" yet (B-463b); a ready conversation is played in the journal with A until NPC talk exists (B-471); the hub's journal station still opens the old journal, because V's lines are only there; memories and lore show no NEW mark, replay, place or kind yet, and a finished quest shows no reward line (B-463c).
**Left out:** the tick and arrow icons (a dot and a small arrow stand in), the portraits on conversation rows, the memory scene window.

**Setup:** pull `dev`, build, open the editor. Esc ends PIE in the editor: use the gamepad, or `wor.UI.Journal` and Backspace. For quests use B-397's **HQ-Test** set-up (a secret quest) and any main or side quest asset (`wor.Quest.Print` lists what is started).
