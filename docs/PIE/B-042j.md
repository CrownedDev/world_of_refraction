# PIE — B-042j: Barrier, Shield and Ward absorbers

**Branch:** `feature/B-042j-absorb-family` (merged into `dev`).
**Already proven by tests:**
- `WoR.GAS.Absorb`: each verb catches its hits; uses and pool spend one charge per impact; the order (Ward, Shield, Barrier, oldest first); refill at turn start; a used-up absorber goes; invalid charges are refused.
- The full suite (792) is green.

What changed:
- New absorbers. No skill or item gives one yet; add them with the console.
- `wor.Absorb.Add <Verb> <Magnitude> <Uses|pool> <Turns> [Element]` gives every combatant with a tracker that absorber (Verb: Barrier, Shield, Ward; Turns 0 = until spent).

**Setup:** pull `dev`, build, start the demo fight.
