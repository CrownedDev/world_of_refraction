# PIE — B-351: two sockets and one skill-slot list (D-141, D-145), part 1

**Branch:** `feature/B-351-two-sockets` (in `dev`; written by the cloud writer, built and reviewed on the desktop 2026-11-04).
**Already proven by tests:** `WoR.Inventory.TwoSockets`, `WoR.Loadout.SkillSlotList`, `WoR.Inventory.GearAttach`, `WoR.Loadout.Rules` (an S gem plus an S stone is two S crystals); the `WoR.Loadout` / `WoR.Inventory` / `WoR.Save` / `WoR.Equipment` / `WoR.Pool` / `WoR.Items` subsets green (240, then 176 after the review fixes); data validation 0 new.
**Console (until the gear screen has the list, B-351b):** `wor.Loadout.PrintSkillSlots` shows your primary weapon's one skill-slot list; `wor.Loadout.ReplaceSkill <slot> <ability name>` puts a learned ability (or one of the weapon's built-ins) in a slot; `wor.Loadout.RestoreSkill <slot>` brings back what the slot held. Slots count from 0.
**Save:** version 13 (12 was B-348's on the dev merge), so every older save is wiped with a warning on first load (D-138).
**Setup:** build the branch and start a fresh save.

Once a weapon's skill list is active, built-ins past its tier count drop out of the list (they stay on the weapon).
