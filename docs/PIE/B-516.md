# PIE — B-516: the empty adapter (D-224, asset overhaul stage 2)

**Branch:** `feature/B-516-empty-adapter` (in dev, built and tested on the desktop 2026-11-15).

**What it is:** stage 2 of the asset overhaul (`Design/AssetOverhaulPlan.md` §6). One empty ring asset, `DA_Ring_Adapter`, stands for every ring; what's in its socket names it ("Fire Ring").
- The Equipment screen's add window can now socket a crystal into the ring before the entry goes in. Before, the add window said a new entry's sockets could only change after it was in.
- The Equipment detail shows the piece's own tier (the copy you own), not the asset's.
- Two entries with the same name read apart: "Lightning Ring", then "Lightning Ring 2" (the Equipment list and the quick strip).
- A ring spell's cast reads the ring whose picks hold the spell. Since every ring is now the same asset, the old lookup could read the ring in use instead (a Lightning cast with the Fire ring in use read the Fire ring's crystal).

**Already proven by tests** (`WoR.Loadout.TwoSameRings`, 6 checks):
- the repeat number;
- two Lightning rings of one asset as two Equipment entries, each its own place;
- a cast reads the ring whose picks hold its spell, and the ring in use when both pick it;
- wear lands on the ring in use;
- a preset save and reload keeps both rings by piece id, each with its own picks.

**Not proven:** the add window flow, the quick strip and a battle, seen only in PIE.

## Before you start: the editor step (the editor worker does this)

1. Make `DA_Ring_Adapter` (under `Content/Data/`, in the rings kind folder per ContentNaming):
   - Form **Ring**, **F** tier, no crystal, **no preset spells** (D-224: no skills on gear).
   - Its stat line: one `BaseStatBonus` line, `BonusSpellDamage`, at the value the existing F rings use (read it off one of them; no new number).
   - `ReferencedEffects` empty.
2. Add **three** copies of it to the played character's inventory asset as spare `Rings`.
3. Make sure the pouch carries a Garnet and two Citrines (or use the existing stock).
