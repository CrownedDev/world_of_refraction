# PIE — B-178: paid gear repair in a run

**Branch:** `feature/B-178-run-repair` (in `dev`).

**Already proven:**
- The editor builds, and 489 tests pass; data validation shows no new errors.
- `WoR.Equipment.GearRepair` (4 cases): the price by tier and missing share, the Gold paid and everything repaired to full, nothing paid or repaired when you can't afford it, an unbreakable evolution costs nothing.
- `WoR.Save` (gold case): the run's Gold carries to the next level, is never written to the save, and is cleared when a run starts or ends.
- `WoR.Party.CarriedState` ("starts fresh after the run ends"): wear resets when a run ends.
- Not provable headless: real wear from fights, the Gold across a real level change, and the button. These checks cover those.

**Setup:** start in the hub level with a party whose gear has crystals.

|---|---|---|---|
| 1 | Enter a trial, win a fight in which your gems wore (cast a few Refractions) | Back in the trial | [ ] |
| 2 | `wor.Party.RepairQuote` | One line per worn item (kind, holder, tier, durability, Gold), the total, and the wallet's Gold | [ ] |

| 7 | Leave the trial for the hub, `wor.Wallet.Print`, then `wor.Party.RepairQuote` | Gold 0 (the run's Gold is lost), and nothing carried: every member `nothing carried`, total 0 | [ ] |
