# PIE — B-357e: the remaining evolution readers go through the one resolve path

**Branch:** `refactor/B-357e-evolution-readers` (built and specs green on the desktop 2026-11-09; in `dev`).
**Play change:** none. Every place that read the character's own evolution slot directly (the Evolution infusion source, evolution wear, the slotted-Reality boost, the seat's stats and Amp, the broken-Breakthrough grey-out, the Breakthrough colour, quest conditions, combat tier, the debug prints) now reads it through `GatherAttachedEvolutions` (`ULoadoutComponent::GetCharacterSlotEvolution`). The gear-swap passives and the L2 gear-evolution passives share one "lasting passive" check (`FSkillEffect::IsLastingPassive`). `GetActivePrimaryEvolutionCrystal` / `GetActivePrimaryEvolutionAttachment` have no C++ reader left (kept for Blueprints, marked OBSOLETE).
**Already proven by tests:** the full suite (same results as before: evolution placement, loadout stats, crystal wear and break, memory conditions, infusion).
**Setup:** a character with an evolution in its own (primary) slot, with Breakthrough spells; ideally a Reality evolution for check 3.
