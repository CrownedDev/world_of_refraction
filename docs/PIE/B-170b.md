# PIE — B-170b: action pips 2, the fixed turn rotation

**Branch:** `feature/B-170b-turn-rotation-cloud` (cloud, UNBUILT; stacked on `feature/B-170a-action-pips-cloud`, so build and test that first, then this).
**Already proven by tests (once built):** `WoR.Turns.Rotation` (with the switch on: 2v2 alternates party first and wraps; 4v1 puts the boss after every hero; 2v3 carries the smaller side's rotation across rounds; a fast enemy still just alternates; enemy first strike takes an opening round then leads; the preview matches the live turns; the dead lose their own seat, a smaller side's extra seat passes on, a revive comes back next round; bonus turn, skip and Execution turn as built; a Wind place delay is ignored; the switch is read per fight), plus unchanged at the default 0: `WoR.TurnManager.*`, `WoR.Turns.Belt`, `WoR.Turns.TurnCap`, `WoR.Combat.FirstStrike`, `WoR.Turns.BonusTurn`, `WoR.Combat.RitualFire`, `WoR.Combat.TurnStartOrder`, `WoR.Effects.StatusBreaks`.

**With the switch off (default) nothing changes.** With it on, turns follow the rotation but each turn is still one action: several actions per turn come with B-170c, Wind's action loss and Emerald's ally actions with B-170d.

**Setup:** the switch is read when a fight starts. Type `wor.Turns.ActionPips 1` in the console **before** touching an enemy team (outside the fight). If a fight starts as PIE opens, add `wor.Turns.ActionPips=1` under `[ConsoleVariables]` in `Config/DefaultEngine.ini` for the session (don't commit it).

**Known:** with the switch on, Turn Speed buffs and gear do nothing to turn order (by design, Q-170h). Rounds against a lone boss are longer, and the boss acts once per hero; its damage needs a tuning pass when pips play in full (plan §6). Build choices: Q-170b2.
