# PIE — B-098: weapons stop giving spells (D-027)

**Branch:** `feature/B-098-weapons-no-spells-cloud` (in dev, built 2026-11-12, after B-097). Save v37: older saves are wiped (D-060), start a new game.
**Already proven by tests (green on the desktop):** `WoR.Loadout.WeaponsNoSpells`: a weapon crystal's spells are not listed, slotted, picked, castable or in the menu for a Generic, a Refractor or a Resonator; the weapon's abilities still are; the data stays; `wor.Loadout.WeaponSpells 1` lists them again; a gem's spell slots are ability slots, broken or not (Q-098, Crown). `WoR.Save.GearDetail`: a weapon's spells are not saved, an adapter's are. `WoR.Combat.BrokenSources`, `WoR.Loadout.SpellSlotList` and `WoR.Loadout.GearChangeDrops` now run with the old path on and keep their checks.
