## The tint parameter: User.Color_ (Crown: "Yes, tint only"; the code is B-622)

`NS_Rally_Charge_Distortion`'s tint is now **`User.Color_`** (a vector), the name B-619's `EffectTint::SetSoftTofuColour` writes. Its old `User.Color` is removed. The tint multiplies the three coloured parts: the helix streaks, the sparks, and the core flare (times `User.Brightness_Flare`). The warped-air refraction and the shockwave ring have no colour, so they stay clear whatever the tint. The default is pale white (1.2 / 1.3 / 1.5), so with no tint set it stays clear. It compiles with no errors.
