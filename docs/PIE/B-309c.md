# PIE — B-309c: the save stores the slots (save v46)

**Branch:** `refactor/B-309c-save-slots` (built 2026-11-24).
**Already proven by tests:** `WoR.Save` (a Generic's two weapon sets with an off hand and an adapter, an adapter primary, an evolution primary with two adapters: written as slots in their places and rebuilt) and `WoR.Loadout.CustomLoadouts`, with the full suite.
**Setup:** the QA save only. Version 46 wipes any older save with a warning (D-060), so the first load makes a fresh one: set up the loadouts below, save, quit, load again.
