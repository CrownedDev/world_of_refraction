# PIE — B-627: the Act panel's second tab, a two-line title, End Turn and Defend keys

**Branch:** `feature/B-627-act-panel-tabs-and-keys` (built 2026-11-25).
**What it is:** From Crown's Act panel screenshot.
- The AD / WD durability is now its own small box right of the "Act: ●○" tab, like a second tab. It has the same plate and height, with smaller text. Crown: "it should be a seperate box next to act so it looks like a seond tab".
- A target step's title is two lines: the action's name ("Ritual Strike (Wind)"), then "choose a target" (or "weapon", "infusion") under it. A long title wraps inside the panel instead of running past its edge.
- Keys (Crown: "end turn doesnt have a keybinding lets use g" / "Defend can be R"):
  - End Turn is G, or D-pad Left on a pad, on the main menu. View, its old pad key, would clash with holding View to answer a join request.
  - Defend is R on the main menu. In a target picker R is still the infusion source.

**Already proven by tests:**
- `WoR.UI.BattleHUD`: the durability sits in a tab in the Act tab's row; the title wraps; End Turn's hint has a key (G / D-pad Left); Defend's is R.
- `WoR.UI.CommandMenu.Keys`: the two-line titles, End Turn's action name, and R in a target picker doesn't Defend.
- The full suite plus validation on the final tree are in the hand-off.

**Setup:** a fight with a fighter whose weapon or adapter has a crystal (so AD / WD show), and an action-pips fight for End Turn.
