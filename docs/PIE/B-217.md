# PIE — B-217: requirements read the live run levels

**Branch:** `fix/B-217-live-world-levels` (merged into `dev`).
**Already proven by tests:** `WoR.Requirements.LiveLevels` (5 tests), which checks:
- The live levels start from the asset.
- A Body level raised during the run removes the skill's requirement-gap penalty.
- It also removes the weapon requirement penalty.
- It also clears the Broken Darkness strain deficit.
- The live debug readout shows the raised level.

Full suite: 613 green.
**Setup:** pull `dev`, build, open the editor. Use a character whose authored Body level is below a skill's or weapon's Body requirement (e.g. authored Body 1, requirement Body 4). Start a run.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Before raising anything, attack with the weapon | `[WeaponReq] ... x0.64` in the Output Log; the skill hits weaker (requirement gap) | [ ] |
| 2 | Raise Body in the run (buy or earn levels, or a head start) to the requirement, and attack again | No `[WeaponReq]` line; damage back to full | [ ] |
