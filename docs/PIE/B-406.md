# PIE — B-406: Per-boss cinematics, on trial

**Branch:** `feature/B-406-boss-cinematics-cloud` (cloud pre-write, UNBUILT, from `dev`). Decisions: Q-406 (reference-backed default; change any here).
**Already proven by tests (once built):** `WoR.Combat.Camera` (play rule, cap, named-attack shot, a phase keeps its sequence) and `WoR.Combat.Camera.Director` (empty fields play nothing; no viewer starts at once; an opening holds turn 1 with the HUD hidden then starts it; a phase cinematic on the phase event with the HUD broadcast; a normal enemy never gets one).
**Editor step first:** pick **one** boss. In its `UBossData`, set **Opening Sequence** (Cinematic) to a short Level Sequence with a camera-cut track, and on one phase set **Cinematic Sequence**. The sequences can bind the boss with the tag `Boss` and the party with `Party`. Optional: on one of the boss's skills, tick **Camera Tuning → Named Attack**.

This is a feel sheet and a trial (FeelGuide 9): judge whether the cinematics earn their time, not only whether they happen. Numbers are first guesses (`TODO: tune`).
