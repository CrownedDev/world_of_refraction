# PIE — B-410: gem ability slots take only matching abilities

**Branch:** `feature/B-410-gem-slot-element` (in dev; the cloud branch redone on the weapon-set slot code, built and tested on the desktop 2026-11-14).
**Already proven by tests:** `WoR.Loadout.GemSlotElement` (4 cases). `WoR.Loadout.WeaponsNoSpells` and `WoR.Loadout.SkillSlotList` must stay green.
**Setup:** open the hub, give the player a weapon with a gem attached (e.g. a Garnet, Fire). Every ability is Generic until someone sets **Element** on an ability asset (Details panel, Identity); for check 2 set one ability to an element other than the gem's (e.g. Water) without saving it, or use a test asset.
