# PIE — B-410: gem ability slots take only matching abilities

**Branch:** `feature/B-410-gem-slot-element-cloud` (cloud, UNBUILT: build first).
**Already proven by tests:** `WoR.Loadout.GemSlotElement` (4 cases), once the desktop has run it. `WoR.Loadout.WeaponsNoSpells` and `WoR.Loadout.SkillSlotList` must stay green.
**Setup:** build, open the hub, give the player a weapon with a gem attached (e.g. a Garnet, Fire). Every ability is Generic until someone sets **Element** on an ability asset (Details panel, Identity); for check 2 set one ability to an element other than the gem's (e.g. Water) without saving it, or use a test asset.

| 3 | Put the same Water ability in one of the weapon's first (tier) slots | It goes in | [ ] |
