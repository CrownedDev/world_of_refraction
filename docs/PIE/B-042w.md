# PIE — B-042w: GAS stage 3, part 5m (the resistances on GAS)

**Branch:** `feature/B-042w-gas-resistance` (merged into `dev`).
**Already proven by tests:** `WoR.GAS.ResistanceSources` (6 cases) checks:
- every damage type's resistance, the status bonus and general status resistance on GAS equal the game's resistance getters;
- each resistance source (buffs and curses, the class table, gear rolls, boss rising resistance) is one effect on GAS, updated in place when it changes and put back if something removes it, and `wor.CompareAttributes` names a source carrying the wrong amount;
- general status resistance never goes past its ceiling on GAS.

The full suite (726) is green, including the resistance seam specs (`WoR.Resistance.Seam`).

What changed:
- The resistance getters now report their parts (no number changes).
- On GAS each resistance is built from those parts instead of copied.

**Setup:** pull `dev`, build, start the demo fight.
