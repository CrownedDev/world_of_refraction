# PIE — B-042u: GAS stage 3, part 5k (max HP / EP on GAS)

**Branch:** `feature/B-042u-gas-pools` (merged into `dev`).
**Already proven by tests:** `WoR.GAS.PoolSources` (4 cases) checks:
- max HP and max EP on GAS equal today's numbers, each with one sources effect;
- a max-HP buff comes through on GAS as a whole number, without re-applying anything;
- gear max-HP points are added before the percent, as the game adds them;
- a max set some other way is copied as it is.

The full suite (715) is green.

What changed:
- Max HP and max EP are now built on GAS from the same parts the game uses.
- The game still reads today's numbers, so nothing you see should change.

**Setup:** pull `dev`, build, start the demo fight.
