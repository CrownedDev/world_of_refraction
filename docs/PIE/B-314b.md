# PIE — B-314b: the run layer in the save (Q-314)

**Branch:** `feature/B-314b-run-layer-save` (in `dev`; built on the desktop 2026-11-04).
**What changed:** a trial run saved mid-way (the save after each fight) now keeps its **run layer**: after quitting and resuming, gear found in the run is still run-only (gone when the run ends) and home gear taken on the run still goes back to how it left home (wear and attachments). The **upgrade memory** (the tier a found piece reached, so the next copy arrives at it, D-097) is now saved too. Save version 15 (every older save is wiped, D-138 / D-060). Found crystals and stones were already kept (pouch or storage, never marked run-only). Known edge, as before: a saved run that is never resumed (started outside the hub, or `wor.Save.ResumeRun 0`) drops its layer, so its run finds stay for good.
**Already proven by tests:** `WoR.Save.RunLayer` (a run saved with a home sword worn in the run and a found dagger resumes with both marks; at run end the dagger is gone and remembered, the sword's gem is back to its home wear; the memory survives; no layer is saved outside a run), `WoR.Pool.RunLayer`, `WoR.Save.Run`; the `WoR.Save` / `Pool` / `Trial` / `Economy` / `Inventory` / `Party` / `Net` subsets green (243); data validation 0 new.
**Setup:** start PIE in the hub with a party; the save is automatic (`wor.Save.Now` saves at once).
