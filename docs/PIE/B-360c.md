# PIE — B-360c: a copy's levels and buys are its own (D-150 point 2)

**Branch:** `feature/B-360c-copies-by-member` (in `dev`; built on the desktop 2026-11-04).
**What changed:** when two players bring the same character, the second copy's victory levels are its own: they wait under its own key, the level-drop screen shows each copy as its own row, and placing one raises only that copy. The shop's "Buy for" cycle also lists each copy, so a buy for the second copy lands with it. Before, both copies shared the first copy's levels. The hub NPC toggle still names the first copy on purpose.
**Already proven by tests:** `WoR.Trial.LevelDrops` (a later copy places its own levels under its own key, not the first copy's), plus `WoR.Shop`, `WoR.Economy`, `WoR.Party`, `WoR.UI`.
**Setup:** PIE with **2 players, Listen Server**, both bringing the **same character** (`docs/PIE/B-360b.md` steps 1 and 2). Host's Output Log open.
