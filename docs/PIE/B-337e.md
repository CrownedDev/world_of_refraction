# PIE — B-337e: skill-effect conditions move to the one vocabulary (automatic migration)

**Branch:** `feature/B-337e-condition-migration-cloud` (cloud pre-write, UNBUILT: build and run the specs first).
**Already proven by tests (once built):** `WoR.Conditions.SkillParity`: every condition alone and in AND / OR groups, on all three checks, gives the old answer both read across and through the migrated group; the migration fills once, never overwrites a stored group, leaves an unconditional effect empty; a defense event reads as "Who defended" only on the impact path.
**Setup:** the editor open.
