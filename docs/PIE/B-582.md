# PIE — B-582: quick attack, 1 twice (D-266)

**Branch:** `feature/B-582-quick-attack`.
**What changed:**
- In the new battle HUD, 1 (A on the pad) on the main menu opens the Attack target picker as before. **Pressing 1 again attacks the highlighted target**, the same as clicking its row. So 1, 1 is a quick attack; you can still move the highlight (hover) before the second press.
- The Attack picker now opens on **this fighter's last attack target in this fight**. If that target is dead, or the fighter hasn't attacked yet, it opens on the first target as before.
- The Position picker is unchanged: there, 1 is still Front Row.
- Enter does not confirm (the new HUD has no confirm key yet).

**Already proven by tests:** `WoR.UI.CommandMenu.Keys` "attacks the highlighted target on 1 / A again": two enemies; 1 again attacks the moved highlight; the next Attack picker opens on that target; once it is dead, on the first target; a new fight forgets it. The B-588 Position spec still picks Front Row on 1.
**Not proven there:** real key presses, the marker and camera on screen, a gamepad.

**Written for an agent with `WoRAgentPlayToolset`** (`Conventions/HandsOffPlan.md`). Play on the QA save folder only. Run at `SetWindowSize(Width=1280, Height=720)`, then repeat 1 and 2 at `SetWindowSize(Width=1920, Height=1080)`.
