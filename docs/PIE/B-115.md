# PIE — B-115: crystal wear and Broken Darkness absorption carry between fights

**Branch:** `feature/B-115-carry-gear-state` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Party.CarriedState` (3 cases) checks three things: a worn gem and a destroyed gem are what the next fight starts with; a new run starts from full gear; a born Broken Darkness member's absorbed elements, stacks and overload EP resume.

**What changed:** within a trial run, each fight used to rebuild your crystals from scratch, so wear, the +10 repair after a fight and a gem destroyed at 0 never reached the next fight. Now they do, like HP and EP. A born Broken Darkness member also keeps its absorption (stacks, absorbed elements, EP above max). Strain still resets each fight (Q-115). After a flee, wear carries with no repair (Q-115b). Going back to the hub resets everything.

**Setup:** a trial with at least two encounters; a party member with a gem on its weapon, and if you have one, a born Broken Darkness member. Output Log open.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | In fight 1, cast until a crystal wears down; note its durability at the end (loadout screen, or the wear log lines) | — | [ ] |
| 2 | Start fight 2 | Output Log "[ULoadoutComponent] <member>: carried crystal state restored"; the crystal starts at fight 1's end value plus the +10 repair, not full | [ ] |
| 3 | Let a gem break (reach 0) in a fight | After the fight it is destroyed (essence paid); in the next fight it is still gone | [ ] |
| 4 | Broken Darkness: absorb a few hits (guard elemental attacks) so stacks build, end the fight | Next fight: "[BrokenDarkness] <member>: carried absorption resumed (N stacks ...)"; the EP bar shows the same stacks and any overload | [ ] |
| 5 | Run `wor.Party.Print` between fights | Each member lists its carried crystal durabilities (and absorption for Broken Darkness) | [ ] |
| 6 | Return to the hub and start a new run | Crystals are back at full; Broken Darkness starts on base Darkness with no stacks | [ ] |
