# PIE — B-042j2: absorbers, part 2 (D-092)

**Branch:** `feature/B-042j2-absorb-part2` (in `dev`; built on the desktop 2026-11-04).
**What changed:** Barrier / Shield / Ward (B-042j) now (1) spend on damage-over-time ticks too, (7) count as a guard for "On Guard" effects when you did not guard the hit yourself, (8) leave a fully stopped hit as a hit, not damage (no lifesteal or on-hit burn for the attacker); a Ward can cover one element, every element, or everything; and a skill or item can **give** an absorber: the new effect types Negate Damage (Barrier), Negate Physical Damage (Shield), Negate Element Damage (Ward, by element), Negate Elemental Damage (Ward, every element), and the two "in total" pools. **Payload fields:** Value = the damage it negates, Charges = uses (0 = unlimited), Duration = turns (0 = until spent), Element = the Ward's (empty on a spell: the cast element). The text reads "negate the next 5 Fire damage you take". A re-cast from the same source replaces its earlier charge. **Not in this slice (B-042j3):** Reflect as one GE by tag and element.
**Already proven by tests:** `WoR.GAS.Absorb` (Ward scopes; an authored Negate becomes an absorber; a DoT tick spends the pool; a same-source re-cast replaces, another source adds, fires-once holds); the `WoR.GAS` / `WoR.Effects` / `WoR.Combat` / `WoR.Skills` / `WoR.Defense` / `WoR.Text` subsets green (481); data validation 0 new.
**Setup:** an ability or spell asset with an effect payload of type **Negate Damage**, Value 10, Charges 1, Duration 0, aimed at Self (or `wor.Absorb.Add` from B-042j). An enemy with a Burn.
