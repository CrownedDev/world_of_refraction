# PIE — B-216: resistance per damage type (the seam)

**Branch:** `refactor/B-216-resistance-seam` (merged into `dev`).
**Already proven by tests:** `WoR.Resistance.Seam` (7 tests). For every class and every Caster element, each hit (element × physical type) gets the same buildup resistance as the old code, within float noise of 1e-5. This holds with typed buffs, an element-None buff, a curse, gear rolls and two stones. The spec also checks the damage-type conversions, the `DamageType.*` tags, and that a new profile asset equals the C++ table. `WoR.GAS.Attributes` checks the new Resistance attribute set. Full suite: 585 green.
**Setup:** pull `dev`, build, and open the editor. Start any trial fight with at least one enemy. Open the console with the ` key.

No gameplay number should change. This job only rebuilds how resistance is put together.
