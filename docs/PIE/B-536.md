# PIE — B-536: reach the screens by playing

**Branch:** `feature/B-536-menu-reaches-screens` (in dev, built and tested on the desktop 2026-11-16).

**What it is (Crown):**
1. **Tap Tab opens the game menu**, also in PIE (Esc ends PIE in the editor). Tab again closes it, as Back does. Esc and the gamepad's Menu button still open it.
2. Holding Tab stays the host's answer to a co-op join request: the menu fires only on a quick tap's release.
3. The game menu gains **Forms** (the "Spirit of {character}" screen, B-444), which was console only.
4. The game menu's Loadout row already opens the v2 loadout screen (Equipment, with its Inventory tab). Nothing changed there; the old loadout screen's code stays.
5. Every screen and how it is reached: `docs/Design/InputMap.md`, "Screens and how they are reached".

**Already proven by tests:** `WoR.UI.PauseMenu`: nine pages in order, Forms opens.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Play on `TestLevel_Nav`, pass the title, walk a little. Tap Tab | The game menu opens | [ ] |
| 2 | In the menu, tap Tab | It closes; you can walk again | [ ] |
| 3 | Tab, then Loadout | The v2 loadout screen, on Equipment; RB / LB reach the Inventory tab. Backspace comes back to the menu | [ ] |
| 4 | Tab, then Forms | The "Spirit of {character}" screen. Backspace comes back to the menu | [ ] |

| 8 | Optional, co-op: with a join request waiting, hold Tab 0.5 s | The join request card answers, and the menu does not open | [ ] |
