# PIE — B-223: level drops (D-102)

**Branch:** `feature/B-223-level-drops` (in `dev`).
**Already proven by tests:** `WoR.Trial.LevelDrops` (mini-boss / boss guaranteed levels by tier, an elite's double chance, placing on a spawned member and on one not in the level, refusals with nothing waiting or at 7, a run reset forgets them, the readout); `WoR.Tuning.Baseline` (the two new ladders); full suite green. Not covered by a spec: the fight-to-drop path (an enemy dies, the win rolls, the run gets the levels) and the run-end reset through `ExitTrial` (it opens the hub); checks 1, 6, 9 and 8 cover them.
**Setup:** pull `dev`, build, start a trial run with two party members. Defaults (Q-223): a normal enemy 10 % (F) to 30 % (S), an elite double; a mini-boss or boss 1 (F-D), 2 (C-B), 3 (A-S).
