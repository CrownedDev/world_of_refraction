# PIE — B-467: the title screen

**Branch:** `feature/B-467-title-screen` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.UI.TitleScreen` (6 cases): with no save the list starts at New Game and has no Continue; with a save Continue is first with the place, the party and the time played; time under an hour reads in minutes; New Game's warning says what starting over replaces; the reset notice names both versions; Join a friend and Credits say they aren't built yet. `WoR.Save` unchanged and green.
**What changed (D-202, D-060; mockups `front/title/1_title.png` to `3_new_game_confirm.png`):** the game has a title screen: "WORLD OF REFRACTION", "TALES OF THE VOID", then Continue, New Game, Join a friend, Settings, Credits, Quit. Outside the editor it opens by itself when the game starts. The save now counts the time played.
**Decided by default (Q-467, Crown may change any):** the title sits over the first level (no title map), and Continue just closes it; in the editor's PIE it does **not** open by itself (console `wor.UI.Title`); after New Game's hold the save is deleted and **the new game begins the next time the game starts** (starting it at once comes with the new game screen, B-469); Join a friend and Credits are listed and say they aren't built yet (B-459, B-470); time played counts from this build on (older saves start at 0 min).
**Left out:** the nebula and the hexagon vortex (an editor step, B-467b); the ornament under the title; the version text bottom left.

**Setup:** pull `dev`, build, open the editor, PIE in the hub. Checks 9 to 11 delete your save: do them last, or skip them.
