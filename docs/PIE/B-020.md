# PIE — B-020: one table for stat buffs and debuffs

**Branch:** `refactor/B-020-stat-modifier-table` (in `dev`).
**Already proven:**
- The editor builds, and every test passes, including the new `WoR.Stats.Modifiers` spec (18 checks).
- 14 of those checks were written and passed on the old code first. They pin how a buff and a debuff move each stat:
  - Action Speed and Spell Speed, and both defense windows
  - Spell Damage and Raw Damage
  - Luck, Reflex, Status Multiplier, Efficiency, Defense and Crit Damage
  - the odd ones: Resistance, element-keyed Status Multiplier buffs, and a negative Crit Damage Up
- They still pass after the change, so the numbers are the same.

**What changed for the player:** nothing. Behind the scenes, each stat's buff and debuff now come from one table instead of being added up separately in 13 places. There are two new console commands:
- `wor.CompareStats` snapshots every combatant's stats and says what changed since the last time you ran it. Snapshots are saved under `Saved/StatSnapshots/`, so the comparison works across an editor restart (delete that folder to start fresh).
- `wor.PrintStatModifiers` lists each combatant's active buff/debuff per stat.

**Setup:** open the editor on `dev`, open the Output Log, and start a fight where someone has a buff or debuff skill (Defense Up, a speed buff, a Luck buff…).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Start the fight, then type `wor.CompareStats` | One `[CompareStats] <name>: first snapshot` block per combatant, listing ActionSpeed, Defense, CritDamage and so on | [ ] |
| 2 | Type `wor.CompareStats` again without doing anything | Every combatant says `identical` (green on screen) | [ ] |
| 3 | Cast a buff or debuff, then type `wor.PrintStatModifiers` | The affected combatant shows that stat, e.g. `Defense +20.0%`; the others show `no active stat modifiers` | [ ] |
| 4 | Type `wor.CompareStats` | Only the affected combatant lists changed lines (its stat and its `Net…` line); the others say `identical` | [ ] |
| 5 | Stop PIE, delete `Saved/StatSnapshots/`, start the same fight with no buffs and run `wor.CompareStats`. Restart the editor, start the same fight again and run it once more | The second run says `identical` for every combatant: the same stats after a restart | [ ] |
| 6 | Play a few turns with buffs and debuffs flying | They feel as before: speed buffs move turn order, Defense Up cuts damage, debuffs weaken | [ ] |
