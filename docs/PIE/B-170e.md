# PIE — B-170e: action pips 5, the placeholder UI (Q-170e2)

**Branch:** `feature/B-170e-action-pips-ui-cloud` (cloud pre-write, UNBUILT; dev merged in 2026-11-12, B-391 is in dev). **Crown's answers (2026-11-12):** the turn ends automatically at 0 actions; the End Turn button ends it early (banking the rest); **no End Turn key yet** (it comes later, with its InputMap row); a saved per-player setting hides the button (default shown).
**Already proven by tests (once built):** `WoR.Combat.ActionPipsText` (pips "●●○", a bank past Max all filled, Max line "Max 3 (+75/100)" and "Max 5" at the cap, the card line, cost labels "(2 actions)", the two greyed reasons). `WoR.UI.BattleHUD`: with the switch on, the party card's line matches and follows a gain, no line on the enemy card, the menu widget has an End Turn row with no key hint and pressing it passes the turn; with the switch off, no line and no End Turn row. `WoR.UI.CommandMenu.Keys`: no End Turn key is bound; a main-menu End Turn press ends the turn and spends nothing (switch on), finds no button (switch off, or the player hid it), does nothing outside the main menu.

**Needs the new HUD** (`wor.UI.NewHUD 1`, the default). **With `wor.Turns.ActionPips 0` (default) nothing changes:** no pips, no End Turn, no cost labels.
**Setup:** type `wor.Turns.ActionPips 1` **before** the fight starts. A default character has Max 2 and regains 1 per turn; `wor.Actions.AddPoints 175` makes Max 3 with progress 75.
**No editor step.** The hide setting is a console placeholder until the settings screen (D-024): `wor.UI.HideEndTurn 1` / `0`.
