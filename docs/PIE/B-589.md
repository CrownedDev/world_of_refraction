# PIE — B-589: Revive names the opponent (Q-450 = B, D-187)

**Branch:** `feature/B-589-revive-name`.
**What changed (Q-450 = B):**
- The rest menu's revive row at a beaten mini-boss's rest spot reads **"Revive the <name> (1 of 3)"**. `<name>` is the encounter's leader, which for a mini-boss is its form. The old row read "Revive the mini-boss…".
- Every revive vote line names it too:
  - "<starter> wants to revive the <name>: vote in the rest menu, or type wor.Trial.Vote yes / no."
  - "Everyone agreed: the <name> returns." / "… returns when the fight ends."
  - "The <name> is not revived (not everyone agreed)."
  - "The <name> already returns when the fight ends."
  - "Everyone agreed, but the <name> can't be revived now."
  - A client's refused press: "The <name> can't be revived from here right now."
- With no rest spot to revive, the line is "There is no one to revive here.". A spot with no name says "the opponent".

**Already proven by tests:** `WoR.Trial.MiniBossRevive` covers:
- the spot keeps the name it was spawned with;
- the row text, and the real rest menu's row (`GetReviveRowText`), are "Revive the Ash Warden (1 of 3)";
- each of the seven vote lines says "the Ash Warden" and no "boss";
- a spot with no name falls back to "opponent".

**Not proven there:**
- that the live encounter's first team member is the mini-boss and not a minion;
- the co-op client's row, which comes through `Client_OpenRestMenu`;
- the look.

**Written for an agent with `WoRAgentPlayToolset`** (`Conventions/HandsOffPlan.md`). Play on the QA save folder only. Run at `SetWindowSize(Width=1280, Height=720)`.

**Reaching the menu:** no console command opens a mini-boss's rest menu. `wor.Trial.Rest` opens the menu at a "ConsoleRest" spot, which has no Revive row (check 4 uses this). To get the row:
1. Start a trial run with a mini-boss on the map (an encounter of rank Mini-boss; `wor.Trial.PrintTeams` lists the map's enemy teams and whether each is beaten).
2. Beat it.
3. Back on the map, walk to the rest spot that appears where it stood, and press **E**.

`wor.Trial.PrintRestSpots` lists the spots. `wor.Trial.ReviveVote` prints a vote's state.
