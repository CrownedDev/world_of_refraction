# PIE — B-042h: GAS stage 3, part 3b (effect lifetime on GAS)

**Branch:** `feature/B-042h-gas-effect-lifetime` (merged into `dev`).
**Already proven by tests:**
- `WoR.Effects.Baseline` gives the same results with `wor.Effects.UseGAS 0` and `1`; at 1, GAS's turn tracker now owns how long each effect lasts.
- `WoR.GAS.EffectLifetime` (7 cases):
  - a timed effect's GAS copy is counted by the tracker;
  - the game's own record follows the tracker's count and goes when the tracker ends it;
  - a refresh restarts the count;
  - removing an effect (cleanse) ends it on GAS too;
  - gear effects and `UseGAS 0` stay as before.

The full suite (740) is green.

What changed:
- Nothing with the switch off (the default).
- With `wor.Effects.UseGAS 1`, how long buffs, debuffs, stuns and other timed effects last is counted on GAS. The game's own record copies it.
- Damage and heals over time still pay through the game's own code (they move with B-042y).

**Setup:** pull `dev`, build, start the demo fight. Open the console (`~`).
