# PIE — B-085: loadouts follow the gear you own

**Branch:** `refactor/B-085-owned-gear-truth` (in `dev`).

**Already proven:**
- The editor builds, and 540 tests pass; data validation shows no new errors.
- `WoR.Inventory.OwnedGearSync` (6 cases):
  - two authored loadouts holding the same sword both link to the one owned sword, once;
  - a gem attached to (or taken off) the owned sword shows in both loadouts;
  - wear during the fight stays on the active loadout, then is written to the owned sword and the other loadout;
  - switching loadouts writes the outgoing one back first, so the incoming loadout gets the worn sword;
  - levelling the sword shows the new tier in both loadouts;
  - a primary-slot evolution links to the owned one and leaves the loadout when it's dismantled.
- Not provable headless: a real fight's wear and between-fight repair, the trial's carried gear, and the debug dump in a played character. These checks cover them.

**Setup:** none. Use a character whose authored inventory owns the weapon (or ring, or evolution) its loadout uses, as the test characters do.
