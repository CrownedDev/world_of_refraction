# PIE — B-359: one weather baseline

**Branch:** `feature/B-359-weather-baseline` (in `dev`; built on the desktop 2026-11-04).
**Already proven by tests:** `WoR.Weather.Baseline` (3: the trial's element at the start, the boss's element and phase intensity at a phase, no move with the leaders' HP), plus the `WoR.Boss` and `WoR.Trial` subsets.
**Setup:** a trial with an element set (e.g. Fire) and a boss fight in it. Open the Output Log. The sky itself does not change yet: the per-element look is B-189; this job only decides the element and intensity (`wor.PrintWeather` shows them).
