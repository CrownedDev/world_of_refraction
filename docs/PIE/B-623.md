# PIE — B-623: 9999 of every resource

**Branch:** `feature/B-623-debug-max-resources` (built 2026-11-25 from dev aecd48492).
**What it is:** Crown: "also ensure that we have 9999 or infinete resources". The console command `wor.Debug.MaxResources` raises every currency the party's wallet holds to 9999 and saves. That covers both run and hub money (shown as Prisms and Gold), Diamond, Dormant Essence (gear and skills), Elemental Essence, Pillar Essence and Mentor Tokens. A balance already above 9999 stays as it is. Every shop, upgrade, repair, level-up and curse cost is paid from these balances; no upgrade uses up a separate material item, so nothing else needs topping up.
**Already proven by tests:** `WoR.Debug.MaxResources` checks that every balance reaches 9999, that a higher one is kept, and that a second run changes nothing. The full suite plus validation on the final tree are in the hand-off.
**Note:** run money (shown as Prisms) is not saved in the hub, and it starts at 0 on every trial start (B-178). Type the command again inside a trial for in-run vendors. The host runs it; on a co-op guest it refuses.
**Setup:** the QA save (slot 0), in the hub.
