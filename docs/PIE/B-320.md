# PIE — B-320: always one valid primary (D-116)

**Branch:** `fix/B-320-always-a-primary` (merged into `dev`).
**Already proven by tests:**
- `WoR.Loadout.AlwaysPrimary`: an empty active primary is filled with the first usable owned weapon (an adapter for a Generic with no weapon; never for a Resonator); a primary adapter can't be dismantled.
- `WoR.Economy.DismantleEquipped`, `WoR.Inventory.OwnedGearSync`: dismantling any loadout's primary (weapon, adapter, evolution) is refused; a secondary still dismantles with no ghost copy left.

What changed: you can't dismantle the gear a loadout uses as its primary; swap another in first. A loadout loaded with no primary picks up your first usable owned weapon (a warning in the Output Log). Defaults in Q-320: only the active loadout is filled; a member who owns nothing usable stays empty.

**Setup:** pull `dev`, build. The hub with the gear / dismantle screen; a Generic owning two weapons.
