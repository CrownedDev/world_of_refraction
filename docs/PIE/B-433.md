# PIE — B-433: a guest's memory find needs the guest to be there

**Branch:** `fix/B-433-memory-report-reach` (in dev, built 2026-11-14; written by the cloud, built and tested on the desktop).
**Already proven by tests:** `WoR.Memory.Sources`: a map-spot or fragment find reported with no character, or with the character far from every memory spot, is refused; a find with the character standing at the spot is noted; finds from other sources (bound gear) are noted as reported.
**What changed:** the host refuses a guest's memory find at a map spot or fragment unless the guest's character is within 600 cm of some memory spot or fragment. A safety check; nothing changes for an honest find.
**Setup:** 2 players (host + one guest), a level with a memory spot and a memory fragment.

|---|---|---|---|
| 1 | **Guest:** walk into a memory spot | The memory unlocks for the guest as before; no `[MemoryUnlock] … refused` warning in the host's Output Log | [ ] |
