# PIE — B-618: skill sounds

**Branch:** `feature/B-618-skill-sounds` (built 2026-11-25 from dev 4d451b497).
**What it is:** a skill now has a sound list (`SFXArray`, under Animation, next to the VFX list). A **Notify** sound plays when the montage's SFX notify fires (its Index picks the entry); an **Impact** sound plays at the target on each landed hit and when a projectile lands. A guarded or dodged hit plays no skill impact sound (Q-618).
**Already proven by tests:** `WoR.Presentation.SkillSounds` (impact sounds on Hit and Crit only, in order; soundless entries skipped; the debug line) and the full suite plus validation on the final tree: 2621 passed, 0 failed; validation 0 new.
**Not proven:** hearing them in game; co-op clients don't hear them yet (TODO).
**Setup (editor worker first):** on Force Strike (`DA_` ability) add to `SFXArray`: entry 0 Notify, Sound SC_Wind_Slash_Cue (the C++ strike montages carry an SFX notify at Index 0, at the swing); and, if there is a hit sound, an Impact entry. Turn on `wor.SkillSFX.Log 1` to see each sound in the Output Log.
