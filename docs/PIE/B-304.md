# PIE — B-304: unified loadout 4, one active-slot rule

**Branch:** `refactor/B-304-active-slot` (merged into `dev`).
**Already proven by tests:**
- `WoR.Loadout.ActiveSlot`: the getters return the active slot's gear; an empty active slot falls back to the first usable one; a weapon another member wears is skipped; a Generic's secondary weapon gets the spell checks.
- The full suite is green.

What changed: one rule picks the weapon in hand and the adapter in use. Same as before in normal play, except the Q-304 cases: a Generic showing an emptied primary now fights with its secondary (was unarmed); a Resonator with a stale adapter index uses its first adapter (had none). A Generic's secondary weapon now has its spells checked like the primary: off-element spells authored on it are cleared.
