# PIE — B-371: code-built skill cameras (wind-up, Cast, impact, blend back)

**Branch:** `feature/B-371-shot-patterns-cloud` (cloud pre-write, UNBUILT, on `feature/B-370-cinematic-window-cloud`: build and run the specs first).
**Already proven by tests (once built):** `WoR.Combat.Camera` "shot patterns": each shot's camera from a fixed frame (shoulder, push-in, FOV punch and shake larger on a crit, pull-out for several targets, follow the projectile), the tuning changing it, a skill's own `CameraSequence` winning.
**Setup:** a fight with a melee ability, a projectile spell and a skill that hits several targets, none with a `CameraSequence`. Camera movement on, skill cinematics on. `wor.Camera.Print` prints the shot now playing.
**Crown approves the look here (B-157).** The numbers are first guesses (`CombatCameraShots` in `CombatCameraTypes.cpp`, `TODO: tune`).

A heal or buff deals no damage, so it holds the wind-up until the next turn; timing the shots by the Cast / Impact notifies themselves is a follow-up if Crown wants it.
