# PIE — B-219: one damage maths core

**Branch:** `refactor/B-219-damage-math-core` (merged into `dev`).
**What changed for players:** nothing. The damage maths moved into one function (`WoRDamageMath::Compute`) that GAS will reuse; every number should be the same.
**Already proven by tests:** `WoR.Damage.MathCore` (8 tests), which checks:
- The attacker multiplier and defense.
- Crit by roll and forced.
- The stat cap.
- Base 0 and minimum damage.
- Defense is gathered for abilities and spells.
- One random draw per hit that can crit, and none otherwise (the fight's random order is kept).
- The debug readout.

The existing `WoR.Damage` and `WoR.AI.DamageEstimate` tests are unchanged and green. Full suite: 608 green.
**Setup:** pull `dev`, build, start any trial fight.
