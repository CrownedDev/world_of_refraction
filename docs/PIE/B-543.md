# PIE — B-543: menu UI fixes (D-230 addition, from Crown's PIE)

**Branch:** `feature/B-543-menu-ui` (in dev, built and tested on the desktop 2026-11-16).

**What it is (Crown):**
1. **Inventory:** a **Loadout** tab next to Gear (Gear, Loadout, Pouch, Chest). It opens the Equipment (loadout) screen for the same character; Back comes back.
2. **Inventory, Gear tiles:** an adapter shows the **adapter icon** (the frame with its crystal) instead of the letter A.
3. **World prompts** ("E  Open · Mirror") no longer draw over an open menu.
4. **Game menu:** the page descriptions ("Character: Pillars, substats and resistances.") are hidden at first; **Help** (H, the pad's View button, or a click on the Help hint) shows and hides them.
5. **Game menu:** the money row sits on the **right** of the header and shows every balance: Gold (Prisms in a run), Diamond, Gear Essence, Skill Essence, Elemental Essence, Stat Essence (a run adds wipes left).
6. **Pillar essence is now called Stat Essence** everywhere the player reads it (D-235): the shared name table, so the menu, vendors, rest spot and curse clearing all follow.

**Not changed (flagged):** the loadout screen's own Inventory tab (B-531) stays. Sending it to the inventory screen would lose wearing a piece straight from the list (the inventory screen has no Wear). The shield tile still shows **W**: the icon table has no picture for the shield's weapon type.

**Already proven by tests:** `WoR.UI.InventoryScreen` (adapter icon; Loadout between Gear and Pouch), `WoR.UI.PauseMenu` (Help off at first and toggles; every balance, the place's money first), `WoR.Text.GameNames` (Stat Essence).
