# PIE — B-503n: the test gear grant (Q-503n)

**Branch:** `feature/B-503n-test-gear-grant` (in dev, built and tested on the desktop 2026-11-15).
**What it is:** a console command that gives the played character test gear through the real game calls, so the whole chain can be tried: get the gear, build the loadout in the v2 screen, use the wheel and the strip in a trial, then a fight.

`wor.Debug.TestGear [fill] [refractor|resonator|bd|reality]`
- **No argument:** gives a plain sword (Arming Sword), a ring (the Generic ring) and one F-tier Fire (Garnet), Water (Sapphire) and Lightning (Citrine) crystal in the pouch. Anything already owned or carried is not given again. The Output Log and the screen list each piece, then the field attack stops.
- **`fill`:** also builds the loadout the screen's way: the sword and the ring go in as entries where the class has room, then a crystal goes in each empty crystal socket (a weapon Fire, then Lightning; the ring Water; never an element the loadout already has).
- **A variant:** first takes every entry but the first out, then sets the class (and innate) until PIE ends. `refractor` = Refractor, innate kept (Fire if none); `reality` = Refractor with Reality; `bd` = Refractor with Darkness and Broken Darkness on; `resonator` = Resonator.

**Already proven by tests:** which crystal the fill puts in which socket.
**Not proven:** everything on the played character (the grant, the fill, the variants); whether the two test assets come with a crystal already in them.
**Note:** the gear given and the loadout built are saved like any gear. The variant's class is not: it goes back when PIE stops.
