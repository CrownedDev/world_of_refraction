# PIE — B-191: reaction triggers

**Branch:** `feature/B-191-reaction-triggers` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Reaction.Trigger` (4 cases) checks four things: a reaction fires when one character wears every listed item facing the listed character, and not with one item missing or facing someone else (once per fight); an effect aimed at Enemy lands on the faced character and one aimed at Self on the wearer; a run memory weakens the boss it names and leaves the others; a weakening and a strengthening memory cancel, and two weakenings go further than one.

**What changed:** you can author **reactions**: "if one of my characters wears these items while facing this character, do this". They are checked when a trial fight starts. Their effects work now; their quest and dialogue are only written to the log for now. Memories collected this run that name a boss now weaken or strengthen it.

**Setup:**
- Create a Reaction Trigger Data asset (Data Asset > ReactionTriggerData). Add one trigger: Required Items = a weapon your party member uses; Facing Character = an enemy's Character Data; Effects = one effect with a payload MaxHPDebuff, Value 20, Target Enemy, Permanent on; Dialogue Id = Test.
- Put that enemy on a trial map (an enemy team or a boss arena).
- Optional (memory): in a Memory Data asset add a Boss Modifier (that enemy, Weaken), and place its fragment on the map (B-190).
- Output Log open.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Run `wor.Reaction.Print` | "1 reaction trigger(s)" and your trigger's line (item, character, 1 effect, dialogue Test) | [ ] |
| 2 | Start the fight against that enemy with the weapon equipped | Output Log: "[Reaction] <id> fired: ... (quest None, dialogue Test)" and "Reactions: 1 of 1 fired (1 effects)" | [ ] |
| 3 | Look at the enemy's HP bar | 20% lower max HP than without the reaction | [ ] |
| 4 | Fight it again with a different weapon | "Reactions: 0 of 1 fired" | [ ] |
| 5 | (Memory) Pick up the fragment, then start the fight | "[Reaction] Memories weaken <enemy> by 15%" and "memory boss changes: 1" | [ ] |
