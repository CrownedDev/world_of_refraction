# PIE — B-214e: field skills part 5 (teleport, phase step, mark and recall, super launch, regroup)

**Branch:** `feature/B-214e-advanced-moves` (in dev; written by the cloud, built and tested on the desktop 2026-11-14).
**Already proven by tests:** `WoR.Field.Advanced` (the fight / cooldown / EP refusals; teleport, phase step, mark then recall, super launch and regroup each moving the pawn in an empty world; paid only when it happened). Not provable headless: real walls, the glide after a super launch, co-op Regroup.
**Setup:** pull the branch, build, play a trial map with walls and a thin wall or bars. Give the leader 20+ EP. For each check: `wor.Field.Unlock <Type> <element>` and `wor.Field.Set Innate <Type>` (the leader's element must match).
