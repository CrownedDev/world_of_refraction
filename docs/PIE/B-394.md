# PIE — B-394: where a cast's visual comes from (D-170)

**Branch:** `feature/B-394-cast-vfx-source` (the cloud's `feature/B-394-cast-vfx-source-cloud` on dev; built on the desktop 2026-11-12; merged into `dev`).
**Already proven by tests:** `WoR.Presentation.CastVisuals`: a weapon's ability and weapon-crystal spell play the weapon's `CastVFX`; a Resonator's pistol adapter plays the pistol default; a Refractor's innate spell the ring default; a Generic wearing both follows the class preference (Adapter or Weapon); a weapon with no `CastVFX`, no defaults asset or an adapter type without a row falls back to the skill's own visual; a spell item plays its own.
**Setup (editor):**
- The defaults asset `/Game/Data/Combat/DA_ImpactVisualDefaults` (an **Impact Visual Defaults** data asset; create it there if B-369's PIE hasn't yet). Its new **Cast Visuals** section: add an **Adapter Cast VFX** row `Ring` → one of the `NS_Magic_Circle1_*` systems (AssetAudit "Ring cast VFX"). Leave **Generic Cast VFX Preference** at `Adapter`. Press **Print Defaults**: the log ends `Cast: Generic preference Adapter, 1 adapter type(s)` and `Ring cast: NS_Magic_Circle1_…`. Restart the editor after creating the asset (it is looked up once).
- One sword's **Weapon Data**: the new **Visuals → Cast VFX**, set to any clearly different system (e.g. a `Fire_Muzzle*`).
- For the verbose lines: `log LogWoR Verbose`.

**Known (Q-394):** innate and evolution spells use the adapter-type default (Ring without an adapter); the Generic preference is one class value, not a per-character setting; a burst projectile fired after its action ended plays the skill's own flash. Only the cast flash (the Muzzle visual) is chosen here: trails, impacts (B-369) and parry effects (B-393) are not.

**Known:** the cast source is resolved where the action runs (the host); a co-op client sees cast visuals once client visuals land (B-231c2). A skill with several Muzzle entries plays the same weapon or adapter visual on each (intended). The first cast after a visual is authored loads it on the game thread (a small hitch, as other VFX entries).
