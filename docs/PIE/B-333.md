# PIE — B-333: seven balances (D-125)

**Branch:** `feature/B-333-seven-balances` (in `dev`; written in a cloud session, built and tested on the desktop).
**Already proven by tests:** `WoR.Economy.SevenBalances` (new), `WoR.Economy.RoundTrip`, `WoR.Economy.Numbers`, `WoR.Economy.GenericSpellPrice`, `WoR.CrystalBreak`, `WoR.Save`, `WoR.Text.GameNames`, once built.
**Setup:** pull the branch, build, open the editor. **Your old save is wiped** on the first load (save version 11, D-060): expect one `[Save] ... below the minimum 11: wiped (D-060)` warning. Start a trial or the hub with a shop. Grant essence first with `wor.Wallet.Add`: a fresh v11 save starts every balance at 0 and nothing drops essence until B-073 (Q-333, Crown: accepted, no starting grant).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Open the console, type `wor.Wallet.Print` | One line with seven balances: Gold, Prisms, Diamond, GearEssence, SkillEssence, ElementalEssence, PillarEssence (all 0 on a fresh save) | [ ] |
| 2 | `wor.Wallet.Add ElementalEssence 100`, then `wor.Wallet.Add PillarEssence 100`, `wor.Wallet.Add SkillEssence 100`, `wor.Wallet.Add Prisms 2000`, then `wor.Wallet.Print` | Each add logs its new total; the print shows 100 / 100 / 100 and 2000 Prisms | [ ] |
| 3 | Open a shop that sells spells; click a **Fire** (or any elemental) spell | The cost line reads `Cost: Prisms N \| Skill Essence N \| Elemental Essence N` — no Fire, Mind or other typed essence | [ ] |
| 4 | Click an **ability** | `Prisms N \| Skill Essence N` only — no Elemental | [ ] |
| 5 | In a shop that sells stones, click a **stat stone** (e.g. a Defense stone) | `Prisms N \| Pillar Essence N` | [ ] |
| 6 | Click a **gem** crystal (e.g. Garnet) and a **Quartz** | Both show `Prisms N \| Elemental Essence N` | [ ] |
| 7 | Put a spell and a stat stone in the cart | The totals table has rows for Prisms, Skill Essence, Elemental Essence and Pillar Essence (only the ones the cart needs), each with your wallet amount | [ ] |
| 8 | Buy the cart, then `wor.Wallet.Print` | The purchase goes through; each balance dropped by exactly the cart's totals | [ ] |
| 9 | Spend your Elemental Essence down (or start a fresh save and add only Prisms), then try to buy a gem | The confirm button stays disabled / the buy is refused; the Output Log names `ElementalEssence` as short | [ ] |
| 10 | Close and reopen PIE (or travel to another level), then `wor.Wallet.Print` | The new balances (Elemental, Pillar) are still there | [ ] |

**What changed for Crown to check (Q-333, reference-backed defaults):** a crystal or stone now costs its essence on top of Prisms; a spell with no element costs Skill only; upgrading an evolution or a spell with an element costs half the step in Elemental (weapons, adapters and abilities need only Gear / Skill); an evolution costs Elemental ×1.5. Say if any of these should change.
