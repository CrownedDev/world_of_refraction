# PIE — B-156: combat camera (code)

**Branch:** `feature/B-156-combat-camera` (in `dev`).

**Already proven:**
- The editor builds and every test passes, including the new `WoR.Combat.Camera` and `WoR.Combat.Camera.Director` specs.
- The specs check:
  - which mode you see (your turn, someone else's turn, a sequence playing, movement off)
  - which template a skill falls back to (spell, melee or ranged)
  - where each view goes: behind and above for centred-wide, closer and to one side for over-the-shoulder, side-on for tactical, further out on others' turns, and a static view that never moves
  - that every combatant gets a camera for the fight and loses it afterwards

**What changed:**
- Fights now have a camera:
  - **On your turn:** it moves behind the acting character, a bit wide, with the enemies in view.
  - **On an enemy's turn:** it pans out wide.
- Skills have a new **Camera Sequence** field (Presentation). Empty means the skill's type template, and none of those exist yet (B-157 makes them). So for now, **actions keep the turn view**; no cinematic plays.
- There are no settings screen entries yet. Use the console:
  - `wor.Camera.Style 0|1|2`: centred-wide, over-the-shoulder or tactical
  - `wor.Camera.MovementOff 1`: one static wide view
  - `wor.Camera`: prints the camera's state

**Choices made for the basic version (D-078, say if you want them different):**
- With camera movement off, skill cinematics are skipped too.
- Enemy skills will play their cinematics as well (once B-157 makes them).
- A cinematic runs until it ends or the next turn starts.

**Setup:** restart the editor on `dev` (a new component was added to the orchestrator), open the Output Log, and start a test fight from the trial level.
