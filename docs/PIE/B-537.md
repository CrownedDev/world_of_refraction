# PIE — B-537: the title is its own level (D-232)

**Branch:** `feature/B-537-front-end-level` (in dev, built and tested on the desktop 2026-11-16).

**What it is (Crown):**
1. The game starts in a small **menu level**, `L_FrontEnd`, that holds only the title. Continue and New Game's Begin travel to the hub; the title no longer opens over the hub.
2. The game menu's **Quit** outside a run saves and goes back to the title (the menu level). In a run it still abandons the run, back to the hub (D-176).
3. **Play pressed with the hub or a trial level open** goes straight in on the last played character (your save's party leader).
4. **With no save**, Play in the hub or a trial goes to the menu level instead of the Character Template, so you pick a new game there.
5. Until the editor steps below are done, everything works as before (B-535: the title opens over the hub). Nothing breaks in between.

**Already proven by tests:** `WoR.UI.FrontEnd`: the menu level counts only once the default map is not the hub; no save and no leader goes to the menu level, never otherwise and never under tests; Quit goes to the hub in a run, the title outside one, and closes the game while there is no menu level.

## Editor steps (do these first, in this order)

| # | Do this |
|---|---|
| E1 | Make the Blueprint game mode: Content Browser → `Content/Core/` → right-click → Blueprint Class → All Classes → `WoRFrontEndGameMode`. Name it `BP_FrontEnd_GameMode`. Open it; in Class Defaults set **Player Controller Class** to the hub's controller (`BP_HubPlayerController`, the one `BP_Hub_GameMode` uses, so the title has its UI root). Leave Default Pawn Class empty. Compile, save |
| E2 | Make the map: File → New Level → Empty Level. Save it as `Content/Level/L_FrontEnd` (map naming: `docs/Conventions/ContentNaming.md`, new maps use `L_`) |
| E3 | In `L_FrontEnd`: Window → World Settings → **GameMode Override** = `BP_FrontEnd_GameMode`. Save |
| E4 | Only now, with the map saved: in `Config/DefaultEngine.ini`, under `[/Script/EngineSettings.GameMapsSettings]`, change the two lines to:<br>`EditorStartupMap=/Game/Level/L_FrontEnd.L_FrontEnd`<br>`GameDefaultMap=/Game/Level/L_FrontEnd.L_FrontEnd`<br>(Or Project Settings → Maps & Modes: Editor Startup Map and Game Default Map.) Leave `HubLevel` in `DefaultGame.ini` as it is (`TestLevel_Nav`) |
| E5 | In `Config/DefaultGame.ini`, in the maps-to-cook list (the B-278 comment, `+MapsToCook=` lines), add `+MapsToCook=(FilePath="/Game/Level/L_FrontEnd")` so a packaged build has it |
| E6 | Restart the editor (it opens on `L_FrontEnd`). Commit the two assets and the two ini changes on a branch (or ask the writer to) |
