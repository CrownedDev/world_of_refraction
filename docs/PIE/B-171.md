# PIE — B-171: a gear change drops what it breaks

**Branch:** `feature/B-171-gear-change-drops` (in `dev`).

**Already proven:**
- The editor builds, and 545 tests pass; data validation shows no new errors.
- `WoR.Loadout.GearChangeDrops` (4 cases): a Fire spell stays with a Fire gem; taking the gem off drops the spell from both loadouts holding the sword, with a message naming it; swapping in a Water gem drops it; an unrelated problem in the same loadout and a loadout without the sword are left alone.
- Not provable headless: the gear screen's buttons and the message shown to the player. These checks cover them.

**Setup:** a character whose weapon has a crystal and a spell of that crystal's element assigned (as the test characters do). Out of a fight.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Take the crystal off the weapon (gear screen / placeholder, or `RemoveCrystalFromWeapon` from a Blueprint) | Log / message `Removed: Weapon spell '<spell>' requires a crystal...`; the spell is gone from the loadout | [ ] |
| 2 | Put a crystal of another element on | The spells of the old element are removed, with a message each | [ ] |
| 3 | Put a crystal of the same element on | Nothing is removed | [ ] |
| 4 | Start a fight | It starts as before; nothing else was removed from the loadout | [ ] |
