# PIE — B-194: memory journal, V's lines, conversations

**Branch:** `feature/B-194-memory-journal` (in `dev`).

**Already proven:** the editor builds and every test passes. `WoR.Story.Journal` (3 cases) checks:
- V's opening line comes first, and the memory's line only after the memory; no line repeats;
- a conversation unlocks with its memory, plays line by line and is logged as played at its end;
- lore is kept once per object, and memories and lore show on the journal page.

**What changed:**
- A new **Story Lines Data** asset holds V's lines and conversations, each naming the memory ids it needs.
- In the hub, a **Hub Journal Station** (Press E) opens a placeholder journal with three pages: Journal (memories, lore and played conversations to reread), Talk to V, and Conversations.
- Lore you read in a trial is now kept in the journal.
- **PLACEHOLDER UI:** plain C++ buttons, replaced by the CommonUI journal later.

**Setup:**
- Create a Story Lines Data asset (Miscellaneous, Data Asset, StoryLinesData) with:
  - V Lines: `Opening` (no required memories, text "V: You're awake."), then `AfterMemory` (Required Memories: the MemoryId of a Memory Data asset you have placed as a fragment in a trial, text "V: You remember something.").
  - Conversations: `FirstTalk` (Title "First talk", Required Memories: the same id, Lines: "A: One.", "B: Two.").
- Place a **HubJournalStation** in the hub map.
- Output Log open.
- Placeholder: only **Close** closes it (no Escape yet); close it before leaving the hub.
