# PIE — B-170g: action pips 7, Turn Speed retired

**Branch:** `feature/B-170g-turn-speed-retire-cloud` (cloud, UNBUILT, on `feature/B-170f-ai-actions-cloud`).
**Proven by tests once built:** `WoR.Data.TurnSpeedRetire` (the three Turn Speed effect types warn once and are never refused; Action / Spell Speed effects don't warn; a skill scaling with Turn Speed, a character's Turn Speed points and weapon / evolution Bonus Turn Speed each warn; the `wor.Data.ListTurnSpeed` string names what an asset authors). Re-run unchanged: `WoR.Effects.LegacyTypes`, `WoR.Data.Validation`, `WoR.Turns.MultiAction`, `WoR.Stats.Modifiers`.

**Nothing in play changes.** Turn Speed is retired for **new authoring** only: data validation warns (never errors, Q-170g2) and the Details panel names the fields "(retired)". The speed timeline still reads Turn Speed at `wor.Turns.ActionPips 0`; B-170h deletes it after your PIE of B-170a–g. No code was removed, no Blueprint-visible function or property was removed or renamed (two properties only got an editor display name).

**Setup:** pull the branch, build, open the editor. To validate one asset: right-click it in the Content Browser, **Asset Actions → Validate Assets**, and read the Message Log.

**Known:** reaction triggers (`UReactionTriggerData`) have no data validation, so a Turn Speed payload in a trigger's Effects gets no warning; check 1's list includes them. Stone and fusion instance targets (`FCrystalId::StoneStat`, `FFusionId::BonusStat`) can still be Turn Speed and aren't warned on (runtime data). Gear **rolls** (`GeneratedStatBonus`) still roll Turn Speed until B-170h, so loot at 0 is unchanged (Q-170g2). There is no character sheet yet (`UI_ScreenInventory.md` 3.2); its spec now drops Turn Speed for Max Actions and the regain, and B-170e adds the placeholder Max Actions line. The enum entries stay in the dropdowns (not hidden) so assets that hold them still show their value. B-170h makes these warnings errors when it deletes the reads. Build choices: Q-170g2.
