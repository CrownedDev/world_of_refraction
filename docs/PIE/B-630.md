# PIE — B-630: the journal in three columns (the kind plate, the open entry, Details)

**Branch:** `feature/B-630-journal` (on top of `feature/B-628-party-screen`).
**Mockup:** `docs/Design/screen_mockups/menus/journal/v2/` (1 Quests, 2 Memories).
**Decision:** Q-630 (what Details shows; the game's own kinds; a row click only lights it).
**Already proven by tests:** `WoR.UI.Journal` (each row's facts, the count line, the Details buttons) and the full suite, headless.
**Setup:** the QA save folder only (`-saveddirsuffix=QA`), Play in a new window, in the hub, with a quest or two started and a memory found (the QA kit). Debug: `wor.UI.PrintJournal` logs every page with its facts.
