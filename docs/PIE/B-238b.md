# PIE — B-238b: a finished run's finds go to home storage

**Branch:** `feature/B-238b-run-finds-to-storage` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.Pool.RunLayer` ("sends a finished run's pouch finds to home storage and keeps what was carried before"): finds of a kind already carried and of a new kind both leave the pouch for storage; what was carried before the run stays in the pouch.
**What changed (D-097, Q-238b by the reference-backed default):** a run that ends any way but a quit (win, extract, out of wipes) moves the items found in it from the pouches to home storage. A quit still takes them back (B-439b).
**Known shortcut:** counted per kind for the whole party (as B-439b); if a find went straight to storage because a pouch was full, an item carried from before may go to storage in its place. Nothing is lost.
**Not proven by a test:** the one line in `ExitTrial` that calls it (checks 2 and 3 are that proof).

**Setup:** pull `dev`, build, open the editor, PIE in the hub.
