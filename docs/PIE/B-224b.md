# PIE — B-224b: rank HP per team, enemy HP by tier

**Branch:** `feature/B-224b-rank-hp-per-team` (written unbuilt in a cloud session; the Unreal writer builds, tests and merges).
**To be proven by tests (once built):** `WoR.Trial.RankHealthPerTeam` (team indices, the form-only mini-boss, x6 only for the boss-ranked enemy, x2.2 for a C-tier enemy). `WoR.Trial.Gate`, `WoR.Combat.EncounterData`, `WoR.Balance.Sim.*` still green (the sim's C and S enemies now have x2.2 / x4.8 HP, so its fights get longer).

What changed for play:
- In a fight that caught several teams, each enemy's HP follows **its own team's rank**: a normal team beside a boss stays at normal HP. A mini-boss form is a mini-boss; its teammates are not.
- Enemies can be given a tier (`Enemy Tier` on the character asset): max HP x the tier power (C x2.2, S x4.8). Every enemy is F (x1.0) until authored, so nothing changes yet.
- Fleeing still follows the fight's hardest rank.
