# PIE — B-449: V extracts the party

**Branch:** `feature/B-449-v-extracts-the-party` (in dev, built on the desktop 2026-11-14).
**What it is:** a trial NPC, V by default (Q-449). Talking to V offers **Extract**: the run ends and pays half, as the boss rest spot's Extract does, with no charge on top. V's Extract works wherever V stands.
**Already proven by tests:** `WoR.Trial.NPC` (the NPC is V by default, the prompt reads "Talk · V", Extract is refused outside a run and offered in a run even at a rest spot in the wild).
**Setup:** V is not placed in the trial maps yet (editor step, below). For now: enter a trial, then console `wor.Trial.SpawnV` puts V in front of you. `wor.Trial.PrintNPCs` lists the NPCs in the level.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | In a trial, `wor.Trial.SpawnV`, walk up to V | The prompt (and the on-screen hint) reads "Talk · V" with the interact key | [ ] |
| 2 | Press the interact key | A plain panel: "V", an Extract button, Close. The cursor shows and you can't move while it is open | [ ] |
| 3 | Close | The panel goes; you can move again | [ ] |
| 4 | Talk again, press Extract | The confirm line: "Extract? You keep part of what you earned. Full rewards only for finishing the trial or falling in battle." and a Leave button | [ ] |
| 5 | Press Leave | The run ends and you are back in the hub; the run-end card shows half of what the run had earned (no boss bonus) | [ ] |
| 6 | In another run, rest at a rest spot out in the wild (not a beaten boss's), then spawn and talk to V | The rest menu has no Extract (B-448), but V's panel still offers it | [ ] |
| 7 | In the hub (no run), `wor.Trial.SpawnV` and talk to V | The Extract button is greyed and the panel says "Not in a trial." | [ ] |

**Editor step (for the editor worker):** place one `ATrialNPC` in each trial map, at a rest spot that is not tied to a boss, away from the boss's rest spot (Q-449). Its defaults are V (Display Name "V", Extracts Party on). It is a plain cube until V's model is set on its Feature Mesh.
