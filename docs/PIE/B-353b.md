# PIE — B-353b: no stone feeds a Broken Darkness character

**Branch:** `fix/B-353b-bd-stone-energy` (in `dev`; built on the desktop 2026-11-04).
**What changed:** using a crystal on a Broken Darkness character gives it absorption energy. That was meant for gems only, but Luck, Reflex and Healing stones slipped through the old list of exceptions. Now no stone of any kind gives energy; every gem still does, by tier.
**Already proven by tests:** `WoR.Crystals.StatStone` (every crystal kind: a gem grants tier energy, every stone grants none); the `WoR.Crystal` / `WoR.Items` / `WoR.Inventory` / `WoR.BrokenDarkness` subsets green (57); data validation 0 new.
