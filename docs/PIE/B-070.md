# PIE — B-070: the trial run keeps its trial

**Branch:** `fix/B-070-trial-strong-ref` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Trial.ActiveTrialRef` (1 case) checks that the trial run holds its trial as a real (strong, garbage-collector-visible) reference, not a weak one.

**What changed:** the trial run subsystem used to hold the active trial weakly. In the editor the asset stays loaded anyway, but in a packaged build nothing else may hold it, so it could be dropped mid-run. It now holds it until you leave the trial. Nothing should look different in PIE; this check just confirms nothing broke.

**Setup:** the hub level; Output Log open. The tests prove the reference is strong; only a packaged run (check 4) proves the packaged-build symptom is gone.
