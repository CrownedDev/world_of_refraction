# PIE — B-453a: the screen shake setting

**Branch:** `feature/B-453a-screen-shake-cloud` (cloud, UNBUILT: build first).
**Already proven by tests:** `WoR.UI.Settings` (the new screen shake case), once the desktop has run it; `WoR.Combat.Camera` must stay green.
**Setup:** build, open the game menu's Settings (or `wor.UI.Settings` if that is how B-452 opens it), Accessibility page. A fight with a heavy hit that shakes the camera (a melee attack shot with ShakeScale above 0, e.g. the demo fight).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Light "Screen shake" | Value "Full"; the side panel explains full, reduced to half, or off | [ ] |
| 2 | Press Right twice, then once more | Reduced, Off, then Full again (Left goes the other way) | [ ] |
| 3 | Set Off, start a fight, land a heavy hit | The camera doesn't shake | [ ] |
| 4 | Set Reduced, land the same hit | It shakes about half as much as on Full | [ ] |
| 5 | Close the game and start again | The setting is as you left it (`wor.UI.PrintSettings` shows it) | [ ] |

**Notes / what went wrong:**
- Off stops the shake only: a shot's field-of-view punch and motion blur still play (they are camera movement, B-453b's switch).
