**Branch:** `feature/B-388-main-side-quests-cloud` (cloud pre-write, built and specs green on the desktop 2026-11-09; in `dev`).
**Already proven by tests (once built):** `WoR.Memory.QuestJournal`: a side quest given by a memory is listed with its first goal, then the next, then done; a hidden quest is never listed; main before side; the journal's Quests page shows them; an unknown id gives nothing.
**Setup (editor):** two **Hidden Quest Data** assets (the same asset type as hidden quests):
- **SQ-Test**: Kind **Side**, Title "Test side quest". Start: a memory you can pick up (e.g. a fragment's). Step 1: At Location = a spot on your trial map, Goal "Reach the spot". Step 2: the same, Goal "Reach it again".
- **MQ-Test**: Kind **Main**, Title "Test main quest", Quest Id `MQ_Test`, no starts. One step: win a fight, Goal "Win a fight".

Press **Print Quest** on each: the line shows `[Side "Test side quest"]` and each step's goal.
