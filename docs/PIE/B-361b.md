# PIE — B-361b: Mentor Tokens

**Branch:** `feature/B-361b-mentor-tokens-cloud` (UNBUILT: written without a compiler; build and run `WoR.Currency.MentorTokens` first).
**Setup:** two players in one run (listen server plus one client), or one player with `wor.Wallet.Add MentorTokens 5` to see the rest. Characters must have their skills kept (they join at the next level).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Run `wor.Wallet.Print` | Eight balances, the last "MentorTokens: 0" | [ ] |
| 2 | Finish a trial run (leave by the exit door) with two players in | Each player's MentorTokens goes up by 1 | [ ] |
| 3 | Finish a trial run alone | No tokens | [ ] |
| 4 | Beat a main boss with two players in | Each player gets 1 more | [ ] |
| 5 | Open `wor.UI.Give`, pick one of your skills, your giver, another player's member as receiver, press "Teach" with 0 tokens | A refusal saying it costs N Mentor Tokens and you have 0; nothing changes | [ ] |
| 6 | Get enough tokens (`wor.Wallet.Add MentorTokens 10`), press "Teach" again | "Taught ..."; the other player's member now knows the skill, you still know it; tokens drop by the skill's price (1 at F, 4 at C) | [ ] |
| 7 | Press "Teach" for the same skill again | Refused: they already know it; no tokens spent | [ ] |
| 8 | Teach to one of your own characters | Refused: give it instead | [ ] |
| 9 | Save, quit, reload | The tokens are back | [ ] |
