# PIE — B-074: an encounter can field a team of up to three enemies

**Branch:** `feature/B-074-encounter-data` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Combat.EncounterData` (3 cases) checks three things: a team fields at most three enemies and skips empty entries; an encounter with no team fights its own pawn alone; a 1 v 3 fight starts from the data.

**What changed:** new data asset **Encounter Data** (a list of enemy Character Data, up to three). An encounter on the map (the Encounter component on an enemy pawn) has a new **Encounter Data** field. Set it, and touching that enemy starts a fight against the whole team. Leave it empty and the pawn fights alone, as before.

**Setup:** a trial level with an enemy pawn that has an Encounter component. In the Content Browser: right-click → Miscellaneous → Data Asset → **EncounterData**. Add 3 enemy Character Data to **Enemies**. Set the encounter's **Encounter Data** to it. Output Log open.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | On the Encounter Data asset, click **Print Encounter** (Details panel, Debug) | Output Log lists the 3 enemies | [ ] |
| 2 | Touch the enemy in the trial | Output Log "[EncounterComponent] Join window closed - handing off N v 3 ... team <asset name>"; the battle opens with 3 enemies in a line | [ ] |
| 3 | Fight it out | Each enemy takes turns; you can target each; winning or fleeing returns you to the trial | [ ] |
| 4 | Clear the encounter's Encounter Data field and touch it again (after a reload) | The pawn fights alone, as before | [ ] |
