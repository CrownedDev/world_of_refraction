# PIE — B-474: the active weapon follows the skill; L3 switches (D-207)

**Branch:** `feature/B-474-weapon-follows-skill-cloud` (cloud, UNBUILT; branched from `feature/B-480-entries-sockets-cloud`, so B-472, B-477 and B-480 come with it).
**Already proven by tests (once built):** `WoR.Loadout.WeaponFollowsSkill`.
**Setup:** build, run the tests. Start a fight with a Generic carrying two weapons whose skills differ (e.g. a sword and a hammer). Use the old or the new battle HUD.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | `wor.Settings.SwitchToSkillWeapon` (no argument) | "on" (the default) | [ ] |
| 2 | Open Abilities on the Generic's turn | The weapon in hand's skills, then the other weapon's, each named "Skill (Weapon)" | [ ] |
| 3 | Use one of the other weapon's skills on an enemy | The character switches to that weapon (stance, mesh) and the skill hits with it | [ ] |
| 4 | Next turn, open Abilities | The lists have swapped: the weapon now in hand first | [ ] |
| 5 | `wor.Settings.SwitchToSkillWeapon 0`, open Abilities | Only the weapon in hand's skills | [ ] |
| 6 | Press L3 on a gamepad (or 6) on the main menu | Switch Weapon: the other weapon comes into hand. D-pad Left does nothing now | [ ] |
| 7 | With `wor.Turns.ActionPips 0`, switch with L3, then use the other weapon's skill (setting on) | The skill's switch is refused as the turn's switch is used ("Already switched this turn"); the skill is not run with the wrong weapon | [ ] |
| 8 | Save, quit, Continue; `wor.Settings.SwitchToSkillWeapon` | The value you set is kept | [ ] |
| 9 | Loadout screen: light the weapon not in hand, press L3 (or 6) | It is put in hand (the in-hand mark moves); the hint line shows "L3 / 6  Set active" | [ ] |
| 10 | Co-op (a guest's Generic): use the other weapon's skill | The host accepts it and the guest's character switches | [ ] |

**Not in this part:** the setting on the settings screen (B-452 / B-453), "Set active" in the v2 screen's Y Options (B-476), the new battle HUD's own skill list layout (B-436 pieces).
