# PIE — B-042n: GAS stage 3, part 5d (DOT and HOT ticks on GAS)

**Branch:** `feature/B-042n-gas-dot-hot-ticks` (merged into `dev`).
**Already proven by tests:** `WoR.GAS.TickExecution` (4 cases) checks that a GAS tick pays what the game's tick pays:
- a Fire damage-over-time tick, through the holder's Fire resistance;
- the resistance is read again at each tick (a resistance buff mid-DOT softens the next tick);
- a DOT sized from max HP ignores resistance;
- a heal-over-time tick adds the holder's healing-received bonus and rounds the same way.

The full suite (730) is green, including the existing effect and status specs.

What changed:
- The game's DOT and HOT ticks now use one shared maths function (no number changes).
- GAS ticks use it too; nothing in play uses GAS ticks yet.

**Setup:** pull `dev`, build, start the demo fight.
