# PIE — B-322: a pouch per character

**Branch:** `feature/B-322-per-character-pouch` (cloud-written; built and tested on the desktop, in `dev`).
**Proven by tests:** `WoR.Pool.ItemSlots` (an 11th type in A's pouch goes to storage while B has room; each pouch moves to / from the one storage; members mirror only their own pouch; starting items banked once; auto-equip gives back; an enemy keeps its own; save v9 round trip; a v7/v8 party pouch goes to the leader; a run-only member's pouch goes to storage at run end). `WoR.Save.*`, `WoR.Pool.*` still green.

What changed for play:
- Each character has their **own 10-slot pouch** (D-117, Q-322). What a character finds goes to their pouch; what doesn't fit goes to the shared storage.
- A member's item menu in a fight shows **their own** items only. (Giving items between characters is B-323.)
- An older save's party pouch (and any bought slots) goes to the **party leader** on the first draw.
- `wor.Inventory.PrintSlots` dumps every character's pouch; `wor.UI.Storage` (B-324; `wor.UI.ItemStorage` was deleted by D-131, B-338) shows one character's pouch and the storage, **Next character** cycles the party.

**Setup:** pull the branch, build, run the tests. Start PIE in the hub with a party of two or more. Keep the Output Log open.
