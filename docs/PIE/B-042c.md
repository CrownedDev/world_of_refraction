# PIE — B-042c: GAS stage 3, part 3 (effect mirror, `wor.Effects.UseGAS`)

**Branch:** `feature/B-042c-gas-effect-mirror` (merged into `dev`).
**Already proven by tests:**
- `WoR.GAS.EffectMirror` (7 cases) checks the GAS copy for:
  - a buff (its value and its removal);
  - stacks, and a same-source re-apply;
  - two sources kept apart;
  - a stun's tag, until it runs out;
  - a burn's tag and element;
  - clearing all effects.
- It also checks that one-shot effects and types not ported yet are not copied.
- And that the switch at 1 reads the copy while 0 reads today's effects.
- `WoR.Effects.Baseline` runs all 14 of its cases twice, with the switch at 0 and at 1. Each run ends with the copy matching.

The full suite (670) is green.

What changed:
- Every fighter keeps a GAS copy of its current effects. Today's effect system still runs them, and the copy follows.
- The console switch `wor.Effects.UseGAS 1` makes these questions read the copy:
  - "is this fighter stunned / silenced?"
  - "does it have this effect?"
  - "how big are its buffs?"
- `0` (the default) reads today's effects.
- `wor.CompareEffects` checks the copy against today's effects for every fighter.

**Setup:** pull `dev`, build, open the editor, start the demo fight.

|---|---|---|---|

- If a compare shows red, the Output Log lists the effect type that differs and the fighter's GAS copy.
