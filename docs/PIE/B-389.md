# PIE — B-389: resistance by damage type (D-168)

**Branch:** `feature/B-389-resistance-by-type-cloud` (cloud pre-write, UNBUILT, from `dev` after B-387).
**Balance change:** Crown's Q-389 makes Generic characters take 15% less physical damage and Resonators 15% more (checks 7–8). Everything else should read as before.
**Already proven by tests (once built):**
- `WoR.Resistance.Lines`: a scope line cuts; with the element line it is one resistance capped at 50%; none gives today's number; a Physical line cuts an ability hit and not a spell; a Spell line the other way round.
- **Unchanged numbers:** `WoR.Damage.*` (DamageCalculatorSpec, MathCore, ScopeGAS, DamageScope), CombatNumbersBaseline, ElementDamage, OnePhysicalResistance, ResistanceSeam / ResistanceSources and IgnoreDefense must all pass untouched.

**Setup (editor):** an apparel piece with **Base Resistance → Physical Damage** = 10 (and nothing else). Checks 1–6 are on a **Refractor** (no class Physical line); a Generic adds +15%, a Resonator −15% (checks 7–8).
