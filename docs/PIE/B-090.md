# PIE — B-090: the save (party and currencies kept between sessions)

**Branch:** `feature/B-090-save-keystone` (in `dev`).

**Already proven:**
- The editor builds, and 484 tests pass; data validation shows no new errors.
- `WoR.Save` (4 cases), all through the real save bytes: the party comes back with its members, formation cells and Player/AI control; banked currencies come back but Gold doesn't; the pool's items keep their ids and tiers; an out-of-date save is wiped.
- Not provable headless: the real slot on disk, the load at start, the save points and the wallet carried across a level change. These checks cover those.

**What is NOT kept yet (by design):** gear. Characters still start with their authored gear (B-085 / B-091 / B-124), and quitting mid-trial abandons the run, so you come back in the hub at full health (Q-090, B-208).

**Setup:** start in the hub level. For a clean start, run `wor.Save.Delete`, stop PIE and start again.
