# PIE — B-192: bound gear

**Branch:** `feature/B-192-bound-gear` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Equipment.BoundGear` (3 cases) checks three things: the owner gets the bound bonus in their combat effects and another wearer doesn't; the bonus line is hidden unless the owner wears it; an item with no owner gives its bound bonus to nobody.

**What changed:** a weapon or ring can belong to a character (**Bound Owner**) and carry a **bound bonus** (Bound Effects, effect bundles like the item's own). Only that character gets the bonus; on anyone else the item is ordinary. No screen shows the bonus line yet.

**Setup:**
- Pick a weapon two of your party members can use. In its Details, Bound: set Bound Owner to one of them, and add a Bound Effects entry: an Effect Definition with one effect, payload DamageBuff, Value 50, Target Self.
- Output Log open.

| # | Do this | You should see | Result |
|---|---|---|---|
| 0 | Select the weapon and click **Print Bound Gear** in its Details | Output Log: "<name>: bound to <owner> | bound effects [<definition> (1 effect(s))]" | [ ] |
| 1 | Give the weapon to its owner and start a fight; attack once | The hit is clearly bigger than without the weapon's bonus (and the effect shows in the owner's effects) | [ ] |
| 2 | Give the same weapon to the other member, start a fight, attack | A normal hit; no bound effect on them | [ ] |
| 3 | Run `wor.PrintAllEffects` during each fight | The bound effect is listed only on the owner | [ ] |
