# PIE — B-447: pillar points are bought from a trial NPC

**Branch:** `feature/B-447-pillar-points-from-trial-npc` (in dev, built on the desktop 2026-11-14).
**What it is (D-183, Q-447):** "Buy a point" is gone from the rest spot's level screen. Each run, one of the trial's NPCs sells pillar points; the player finds which by talking. The seller is the same NPC for the whole run and changes between runs. The price is as before (run Prisms, climbing per character). A bought point is still placed at a rest spot.
**Already proven by tests:** `WoR.Trial.NPC` (the seller is one of the placed NPCs, the same one every time it is asked in a run; only the seller sells; with one NPC that NPC sells) and `WoR.Trial.LevelDrops` (a point is bought away from a rest spot; placing still needs one).
**Setup:** the NPCs are not placed in the trial maps yet (editor step, below). For now, in a trial: `wor.Trial.SpawnV`, walk a few steps, `wor.Trial.SpawnNPC Mira`, walk, `wor.Trial.SpawnNPC Toren` (any names). `wor.Trial.PrintNPCs` says which one sells this run. Have some Prisms.
