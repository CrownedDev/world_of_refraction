# PIE — B-208: quitting mid-trial picks the run back up

**Branch:** `feature/B-208-save-trial-run` (in `dev`).

**Already proven:**
- The editor builds, and 548 tests pass; data validation shows no new errors.
- `WoR.Save.Run` (3 cases):
  - a mid-trial run (trial, seed, gate choice, Hard difficulty, a beaten fight, an opened chest, a memory, 25 Gold) survives the save bytes and comes back as it was;
  - nothing is saved as a run outside a trial;
  - carried HP, crystal wear, the primary evolution's durability and absorption stacks come back, and none of it is saved outside a run.
- Not provable headless: the level actually reopening, and the fight and chest staying done in the real trial map. These checks cover them.

**Setup:** start PIE in the hub. The save version went up to 2; an older save still loads (it just has no run).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Enter a trial, win one fight, open a chest, note your HP and Gold | Play as before | [ ] |
| 2 | `wor.Save.Print` | A `Run (B-208): <trial> seed … 1 beaten, 1 found … Gold <n>` line, and a `carried:` line under each party member | [ ] |
| 3 | Stop PIE, start PIE again in the hub | Log `[TrialRun] Restored saved run of '<trial>'` then `[TrialRun] Resuming trial`, and the trial level opens on its own, at the trial's start | [ ] |
| 4 | Walk to the fight you beat and the chest you opened | The fight is gone (beaten) and the chest is open; the trial layout is the same as before | [ ] |
| 5 | Check HP, crystal wear (`wor.PrintInventory`) and Gold | Same HP, same worn crystals and the same Gold as at step 1 | [ ] |
| 6 | Finish or leave the trial back to the hub, then `wor.Save.Print` | `Run (B-208): none (a reload starts in the hub)` | [ ] |
| 7 | With a saved run (repeat 1), stop PIE and start PIE directly in the trial map instead of the hub | Warning `[Save] Saved run of … not resumed`; the game plays as a normal start with full HP, and the run is gone after the next save | [ ] |

A run only resumes when the game starts in the hub. If the start map later becomes a main menu, this needs revisiting.
