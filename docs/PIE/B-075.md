# PIE — B-075: four small fixes (recruit, currency limit, shop close, interact hints)

**Branch:** `fix/B-075-small-fixes` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Economy.CurrencyClamp` checks a balance stops at the limit instead of turning negative. `WoR.Party.RecruitData` checks a recruit joins as its placed pawn's own Character Data, once.

**What changed:**
- **Recruit:** a recruitable character placed in a level whose Character Data is changed on the placed copy (not in its Blueprint) now joins as that character, and pressing interact again dismisses it. Before, it joined as the Blueprint's default character and could never be dismissed.
- **Currency:** a balance can't overflow into a negative number any more.
- **Shop:** if the shop window is removed some other way than its Close button, the game unpauses and you get control back. Before, it stayed paused with nothing to click.
- **Interact hints:** the door and merchant hints ("Press E…") no longer stay on screen after you go through a door or the actor goes away while you stand next to it.

**Not checkable in PIE:** a shop window removed some other way than Close (no such way exists in the game yet); covered by reading the code.

**Setup:** the hub or a trial level with a merchant, a trial door and a recruitable character (Party Interaction component). Output Log open.
