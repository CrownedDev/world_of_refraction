# PIE — B-383: damage scopes (D-166)

**Branch:** `feature/B-383-damage-scopes-cloud` (on `feature/B-382-amp-lines-cloud`; written in the cloud, **not built yet**).
**Proven by tests once built:** `WoR.Damage.Scope` (DamageScopeSpec), `WoR.Damage.Amp`, plus the existing `WoR.Damage`, `WoR.DamageMath`, stat-modifier, GAS stat-getter and effects specs (their numbers must not change: every existing effect is All-scope).
**Setup:** build, open the editor. Pick one skill or gear effect asset that gives a **Damage Buff** (or Modify Damage Dealt) and one that gives a **Defense Buff** (or Reduce Damage Taken). Note their current **Damage Scope** (it should read *All hits* everywhere).
