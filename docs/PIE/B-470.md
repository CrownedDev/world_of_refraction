# PIE — B-470: the credits screen

**Branch:** `feature/B-470-credits-screen` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.UI.Credits` (2 cases): every section has a heading and at least one line, the maker is first; the scroll moves at its speed and five times faster while Select is held. `WoR.UI.TitleScreen`: only Join a friend is refused now.
**What changed (`UIScreens.md` #13, mockup `front/credits/1_credits.png`):** the title's **Credits** row opens the credits: the game's name, then Created by, UI art, Fonts, Assets, Built with, in a centred column that scrolls up on its own.
**Decided by default (Crown may change any):** the text is the mockup's (it lives in code, `WoRCredits::BuildSections`, because a packaged game can't read the repo's `CREDITS.md` files); when the last line has scrolled away the credits close by themselves and you are back on the title.
**Left out:** the title backdrop behind it (B-467b).

**Setup:** pull `dev`, build, open the editor, PIE in the hub.
