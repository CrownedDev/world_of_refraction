# PIE — B-138: the weapon mesh follows weapon changes (no polling)

**Branch:** `refactor/B-138-weapon-mesh-delegate` (in `dev`).

**Already proven:**
- The editor builds, and 462 tests pass; data validation shows no new errors.
- `WoR.Weapons.MeshFollowsLoadout` (9 cases): the weapon mesh component never ticks; switching loadout, a direct loadout edit (once announced) and any inventory change update the shown weapon straight away.
- Not provable headless: the actual meshes in the hands (needs a real character).

**Setup:** open the hub map with a Generic character that has two weapons (or two loadouts with different weapons).
