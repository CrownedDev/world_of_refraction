# PIE — B-211: boss triggers

**Branch:** `feature/B-211-boss-triggers` (in `dev`).

**Already proven:**
- The editor builds, and 521 tests pass; data validation shows no new errors.
- `WoR.Boss.Triggers` (7 cases): the right character wearing the item weakens the boss, someone else wearing it doesn't; weaken + strengthen cancel; a trigger with no conditions or a hidden one never fires; add phase gives the boss one more phase, and two such triggers still only one; nothing fires with no party; a run memory naming the boss leaves it untouched.
- `WoR.Reaction.Trigger` still passes (the old memory path, now unused).
- Not provable headless: the asset registry finding your boss data, the real fight start, and that memories no longer change the boss. These checks cover them.

**Setup (in the editor, needs saving):** on a boss data asset (`UBossData`) whose boss a trial fights, add a **Trigger**: a condition *Gear Worn* (Character = one of your characters, Item = a weapon they can wear), Results = *Weaken* and *Dialogue* (Dialogue Id = anything). If a memory asset had **Boss Modifiers** naming this boss (B-191), leave them: they should do nothing now.
