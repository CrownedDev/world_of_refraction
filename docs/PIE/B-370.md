# PIE — B-370: cinematic window, then the Defence view (D-162, Q-370, Q-370b)

**Branch:** `feature/B-370-cinematic-window-cloud` (cloud pre-write, built and specs green on the desktop 2026-11-08; in `dev`).
**Already proven by tests (once built):** `WoR.Combat.Camera` "the cinematic window": the window is cut to end 0.75 s before the first defendable moment; with no range it runs to the wind-up end (or the read time alone); the per-viewer hand-off (defending → Defence, not → cinematic / watch, movement off → static); the Defence view sits behind the defender facing the attacker, further back for two. The timer and the real view change are PIE-only.
**Setup:** solo, a fight against an enemy whose skill has Impact (or Cast) notifies. Optional: place a **Cinematic Window** notify state on that skill's montage (montage editor → Notifies track → Add Notify State → Cinematic Window). Type `wor.Camera.Print` after each enemy action to see the window line.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Let the enemy attack one of your characters (no Cinematic Window placed) | The camera moves behind your targeted character, the enemy in front, a moment before the first hit; you have time to Guard. `wor.Camera.Print` ends `window ends X s (read time only ...) -> ECombatCameraMode::Defence` | [ ] |
| 2 | Same with a skill that has a RitualCastMontage | The Defence view comes at the end of the ritual leg (or earlier if the hit is close); the line says `wind-up end` | [ ] |
| 3 | Place a Cinematic Window covering the whole montage and repeat | The Defence view still comes 0.75 s before the first hit (`placed`, cut short) | [ ] |
| 4 | An enemy AOE that targets two of your characters | Both are in frame from behind | [ ] |
| 5 | Your own character attacks an enemy | No Defence view; the turn / cinematic view as before. `wor.Camera.Print` says `window: none` | [ ] |
| 6 | `wor.Camera.MovementOff 1`, then let the enemy attack | The one static view stays; no Defence move | [ ] |
| 7 | Guard the hit after the Defence view arrived | The hit reads clearly; tune `MinDefenseReadSeconds` (CombatCameraTypes.h) if 0.75 s feels short or long | [ ] |
