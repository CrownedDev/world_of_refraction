# PIE — B-523: a run starts with no learned skills (stage S3a)

**Branch:** `feature/B-523-run-skill-list` (in dev, built and tested on the desktop 2026-11-16).

**What it is:** D-224 (2). When a trial starts, each member on its class kit puts its hub skills aside. In the run it knows only its innate spells (and its Broken Darkness pools and its own evolution's spells) plus the kit's starting skills, which sit in the skill list, not in a slot (Q9). At the run's end the hub skills come back. Choices taken: Q-523.

**For now (until B-525):** every ending puts the hub list back as it was, so a skill bought in the run is gone afterwards, even after an extract. B-525 keeps the slotted ones.

**Already proven by tests:** `WoR.Run.Skills` (the run starts with the innate spell and the starting bolt only; a skill bought in the run goes in the run list; the hub list comes back at the end; the kept-aside list survives a save). Full suite in the session note.

**Editor step first (no code):** in `DA_Loadout_ClassDefaults`, give the Generic's and the Resonator's kits one generic bolt in **Starting Skills** (`DA_Spell_Bolt` or `DA_Spell_Missile`, whichever exists; or make `DA_Spell_Bolt`, Generic element). Leave each piece's **Skill Picks** empty (Q9: nothing pre-attached). Save.
