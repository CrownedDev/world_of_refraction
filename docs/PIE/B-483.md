# PIE — B-483: key caps in every menu footer, clickable; section frames on loadout v2

**Branch:** `feature/B-483-key-caps-section-frames` (in dev, built 2026-11-14).
**Already proven by tests:** `WoR.UI.KeyHints` (two new cases: a footer read as caps and labels on both devices, a pair as two caps, a sentence left as text, what each cap clicks; a footer and a key label made as caps); every screen's spec stays green.
**Setup:** open the hub with a keyboard and mouse and, for checks 3 and 4, a gamepad; console `wor.UI.LoadoutV2`. Compare the footer with `docs/Design/screen_mockups/menus/loadout/v2/1_weapons_generic.png`.

**Notes / what went wrong:**
- A click is one press: a "Hold: ..." hint (the title's Start over, the credits' faster) is not clickable; use the key.
- Check 10: the left panel is as tall as its rows, so it is shorter than the details box; and its rows are a little narrower than before (the panel's padding). Note it if a long name is cut.
- If a click on a footer hint does nothing in some menu, note the menu and the hint: the click sends that hint's keyboard key to the screen.
- The old hub windows and the battle HUD still have no key caps (they don't use the shared builders).
