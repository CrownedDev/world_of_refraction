# PIE — B-042yb: GAS stage 3, part 3d2 (damage, speed and pillar stats read from GAS)

**Branch:** `feature/B-042yb-gas-stat-getters` (merged into `dev`).
**Already proven by tests:**
- New spec `WoR.GAS.StatGetters`:
  - spell damage, raw damage, action speed, spell speed, Mind, Body and Spirit each give the same value with `wor.Effects.UseGAS 0` and `1`;
  - with the switch on they return GAS's value (an extra bonus only GAS knows about shows up);
  - `wor.CompareAttributes` still compares GAS against the game's own maths.
- `WoR.Effects.Baseline` runs on both paths and is unchanged.
- The full suite (772) is green.

What changed:
- Nothing with the switch off (the default).
- With the switch on, those seven stats come from GAS. Before each read, GAS's copy is brought up to date from the character's gear, stones and buffs, so a change with no event (weather, a crystal breaking) is not missed.

**Setup:** pull `dev`, build, start the demo fight. Open the console (`~`).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Open the editor and watch the Output Log while it loads | No new errors | [ ] |
| 2 | With the switch off, note a spell's damage and an attack's damage on an enemy, and how fast the attack animation plays | Numbers as before | [ ] |
| 3 | Type `wor.Effects.UseGAS 1`, then repeat step 2 on a fresh fight | The same damage numbers and the same animation speed | [ ] |
| 4 | With the switch on, put a damage buff on a character, then attack | The buff raises damage as with the switch off | [ ] |
| 5 | With the switch on, type `wor.CompareAttributes` | 0 combatants differ | [ ] |

**Notes:**
- No behaviour change is intended with the switch on or off. If anything differs, it's a bug.
