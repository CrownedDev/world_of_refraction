# PIE — B-124: a saved weapon or ring comes back whole

**Branch:** `fix/B-124-save-gear-detail` (in `dev`).

**Already proven:**
- The editor builds, and 578 tests pass; data validation shows no new errors.
- `WoR.Save.GearDetail` (4 cases), through real save bytes:
  - a rolled weapon comes back with the same asset, GUID, tier, quality, crystal and its wear, spells and rolls;
  - a ring keeps its crystal and roll;
  - an attached evolution comes back, and an empty spell slot stays empty in its place;
  - a weapon saved before B-124 keeps the asset's default crystal.
- Not provable headless: changing gear in the editor game and restarting. These checks cover it.

**Setup:** the hub with the party. Open the console with the tilde key, and keep the Output Log open. `wor.Save.Print` dumps the save; `wor.PrintPool` the armoury.

| 2 | Attach a different crystal to a weapon (the loadout placeholder), fight once so it wears, return to the hub | The crystal is on the weapon | [ ] |
