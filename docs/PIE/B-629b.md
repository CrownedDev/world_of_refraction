# PIE — B-629b: the skill picker as tiles

**Branch:** `feature/B-629b-skill-picker-tiles` (from `dev` 391dbdfdf).
**Mockup:** `docs/Design/screen_mockups/menus/skills/v1/2_pick_skill.png`.
**Decision:** Q-629b (a skill's picture is the piece it needs; the tier as a badge; Up reaches Fits / all; Q / E filter by weapon type).
**Already proven by tests:** `WoR.UI.InventoryScreen` (the B-629b spec: tiles, selector, filter), `WoR.UI.LoadoutV2Skills`, `WoR.UI.LoadoutSkills` and the full suite, headless.
**Setup:** the QA save folder only (`-saveddirsuffix=QA`), Play in a new window, in the hub. A Generic with a weapon and a few learned skills for it and for another weapon type.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Open the game menu (Tab), Inventory, E twice to Skills, A on an empty slot | The left column is a grid: "Slot N · empty" with "N fit" at the right, the ‹ Fits this slot  All learned › plate, the filter tabs (All, then a weapon picture), then a tile per skill that fits. No list of names | [ ] |
| 2 | Look at a tile | The weapon the skill needs as the picture, its tier badge bottom-left; the legend reads "slotted already" and "can't go here (why: in the details)" | [ ] |
| 3 | Arrows over the tiles | The lit tile moves one tile at a time; the middle column and Details follow the lit skill | [ ] |
| 4 | Up from the top row | The Fits / all plate lights; the hints read Arrows Fits / all, A To the skills | [ ] |
| 5 | Right on the plate | All learned underlined, the count reads "N learned"; skills already in the entry have the tick, skills for other gear are greyed with the lock | [ ] |
| 6 | Down, light a locked tile | Details has a Can't line with the reason; A on it is refused and the picker stays | [ ] |
| 7 | E (RB), then Q (LB) | The tiles show one weapon type's skills, then All again; the lit tab is filled. A click on a tab does the same | [ ] |
| 8 | Click a tile, then click it again | The first click lights it, the second puts it in (a free one): back to the slots with that slot filled | [ ] |
| 9 | A on a slot whose weapon has no learned skill that fits | "No learned skill fits this slot." with the Fits / all plate already lit; Right turns to All learned | [ ] |
| 10 | B in the picker | Back to the slots, the same slot lit; the list of slots shows again | [ ] |
| 11 | A on a slot, then Q / E and Z / C | Q / E turn the filter (not the page) while the picker is open; Z / C change character as before | [ ] |
