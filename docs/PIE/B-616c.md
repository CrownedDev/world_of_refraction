# PIE — B-616c: the Combat Master's skill Upgrade

**Branch:** `feature/B-616c-skill-upgrade` (stacked on `feature/B-616b-vendor-tile-grid`, with `dev` 32a7e89a4 merged in: merge B-616b first).
**Decision:** Q-616c (one tier a press; a skill's own level-up cost; the store's skills, wherever slotted).
**Already proven by tests:** `WoR.UI.VendorScreen` (a new spec: the Combat Master's tabs; the page aims one tier up and refuses an empty wallet; A asks, the second A raises the spell in the pool for one step's cost; a skill at S is refused) and the full suite, headless.
**Setup:** the QA save folder only (`-saveddirsuffix=QA`), Play in a new window, some Dormant Essence and Elemental Essence, a member with a few learned skills (one slotted). Open the Combat Master in the hub (or `wor.UI.VendorScreen CombatMaster`).
