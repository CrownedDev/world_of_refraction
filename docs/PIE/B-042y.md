# PIE — B-042y: GAS stage 3, part 3d (burns and heal-over-time paid by GAS)

**Branch:** `feature/B-042y-gas-getters-hp` (merged into `dev`).
**Already proven by tests:**
- New spec `WoR.GAS.Payouts` runs with `wor.Effects.UseGAS 0` and `1`. Both switches give the same results:
  - a burn hits exactly N times;
  - a heal-over-time heals exactly N times;
  - a lethal burn tick kills through the normal death path;
  - a heal-blocked heal-over-time heals nothing.
- With the switch on, each tick goes through GAS's tick, and GAS's Health matches the HP afterwards.
- `WoR.Effects.Baseline` runs on both paths and is unchanged.
- The full suite (769) is green.

What changed:
- Nothing with the switch off (the default).
- With `wor.Effects.UseGAS 1`, GAS's tick calculation works out each burn and heal-over-time tick. The game's own HP then takes the result, so damage numbers, death and the HP bar work as for any hit.
- When ticks happen is unchanged: at the holder's turn start, exactly N times, and on landing if it lands on the holder's own turn.
- Energy, drains and the stat getters move later (B-042yb).

**Setup:** pull `dev`, build, start the demo fight. Open the console (`~`).
