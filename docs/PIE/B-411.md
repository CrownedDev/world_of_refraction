# PIE — B-411 (part 1): the weapon spell path deleted

**Branch:** `refactor/B-411-weapon-spell-path-delete-cloud` (cloud, unbuilt, from `dev` 2026-11-15). **Merge only after Crown's B-098 PIE** (`docs/PIE/B-098.md`): it deletes the switch B-098's comparison uses.
**Already proven by tests (once built):** `WoR.Loadout.WeaponsNoSpells`, `WoR.Loadout.GemSlotElement`, `WoR.Loadout.SkillSlotList`, `WoR.Loadout.SpellSlotList` (adapter only), `WoR.Loadout.GearChangeDrops`, `WoR.Loadout.Rules`, `WoR.Combat.BrokenSources`, `WoR.Loadout.ActiveSlot`.

**What changed:** nothing a player sees at the default, with one exception: a loadout from an older save that still holds a spell on a weapon now has it dropped (before, a matching crystal kept it in the data, unread). `wor.Loadout.WeaponSpells`, `wor.Loadout.ListWeaponSpells`, `wor.Loadout.PrintSpellSlots`, `wor.Loadout.ReplaceSpell` and `wor.Loadout.RestoreSpell` are no longer console commands.
