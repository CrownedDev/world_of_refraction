# PIE — B-397: hidden quests shown once found (D-171)

**Branch:** `feature/B-397-hidden-quests-shown-cloud` (cloud pre-write, UNBUILT, from dev).
**Already proven by tests (once built):** `WoR.Memory.HiddenQuest`: a hidden quest started by its memory notifies "Hidden quest discovered: …", shows placeholder title and goal when unwritten, and data validation warns for each. `WoR.Memory.QuestJournal`: an unstarted hidden quest is never listed; a found one lists after main and side with its current goal only, moves to the next goal, never shows its later step or end memory before it lands; another player's list (a second game instance) is unchanged.
**Supersedes:** the "Something has begun." / "Something has moved forward." checks in PIE B-377 (1–2), B-377b (2–3), B-381 (2, 6) and B-388 (6): those notices are gone (D-171).
**Setup (editor):** reuse B-377's hidden quest asset (**HQ-Test**: start M-Start's fragment, step 1 win a fight, step 2 a second step, end memory M-End). Give it Title "Test hidden quest", step 1 Goal "Win a fight", step 2 Goal "Win again". Make a copy, **HQ-Blank**, with no Title and no Goals.

| 1 | Run **Validate Data** on HQ-Blank (right-click → Asset Actions → Validate) | Warnings (not errors): one for the missing Title, one per step with no Goal; HQ-Test gives none | [ ] |
