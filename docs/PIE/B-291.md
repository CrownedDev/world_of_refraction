# PIE — B-291: headless seams for the balance simulator

**Branch:** `feature/B-291-headless-seams` (merged into `dev`).
**Already proven by tests:**
- `WoR.Balance.Sim.OneFight`: a 1v1 fight runs headless to the end with both console variables on, rounds counted from `OnRoundAdded`; a montage-less ability lands one impact frame per hit, defended (AI defender). `OnStatusTriggered` is wired to the recorder but not asserted yet (B-292).
- The full suite is green.

What changed: two console variables, both off by default, so normal play is unchanged:
- `wor.Combat.InstantImpacts` (default 0): 1 = a skill with no animation lands its hits at once, and you can defend them; 0 = as before (waits, then lands undefended).
- `wor.AI.ThinkDelayScale` (default 1): scales the enemy "thinking" pause; 0 = no pause.
The impact code was moved into one function the animation path and the no-animation path share.

**Setup:** pull `dev`, build.
