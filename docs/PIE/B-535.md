# PIE — B-535: the game starts on the title

**Branch:** `feature/B-535-title-at-start` (in dev, built and tested on the desktop 2026-11-16).

**What it is (Crown):**
1. The title opens by itself on the first map load of a play session (the hub, `TestLevel_Nav`, the game's default map), PIE included. No more typing `wor.UI.Title`.
2. It does not open again on later map loads in the same session, or when you come back from a trial.
3. It does not open when PIE starts directly in a trial test level, during headless tests, or for a friend joining your game (co-op client).
4. Testing escape: `wor.UI.TitleAtStart 0` skips it (default 1). Put it in the console before Play, or in `Config/DefaultEngine.ini` under `[ConsoleVariables]` to keep it off.
5. `wor.UI.Title` still opens it any time.

**Already proven by tests:** `WoR.UI.TitleScreen`: opens on the default map; not on a trial map, not when switched off, not under tests.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Open `TestLevel_Nav` and press Play | The title is the first thing shown | [ ] |
| 2 | Continue (or New Game). Start a trial, finish it, come back to the hub | The title does not open again | [ ] |
