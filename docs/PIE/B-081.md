# PIE — B-081: gear effects follow a mid-fight swap

**Branch:** `feature/B-081-gear-effects-follow-swap` (in `dev`).

**Already proven:** the editor builds and every test passes. `WoR.Effects.GearSwap` (4 cases) checks:
- switching away from a ring takes its buff off; switching back gives it once (no stacking); the same ring again changes nothing;
- a timed starting effect goes off with its ring and is not given again on the swap back (Q-081);
- nothing changes out of a fight, or after the fight's effects are cleared.

**What changed:** D-008: a weapon toggle or ring switch now swaps gear effects, not only stats. The old gear's come off; the new gear's passives come on; start-of-fight one-shots and timed effects are given once a fight (Q-081).

**Setup:**
- A Resonator with two rings: ring A with a permanent effect (for example a Damage Buff, Permanent ticked), ring B with none or another one.
- Optional: a Generic with two weapons, one with a permanent effect.
- Output Log open; `wor.PrintAllEffects` lists effects.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | Start a fight with ring A active, run `wor.PrintAllEffects` | Ring A's effect is listed | [ ] |
| 2 | Switch to ring B, run `wor.PrintAllEffects` | Ring A's effect is gone (ring B's on, if it has one); log "Gear swap on ..." | [ ] |
| 3 | Switch back to ring A, run `wor.PrintAllEffects` | Ring A's effect is listed once, not twice | [ ] |
| 4 | Generic: toggle weapons | The weapon's effect follows the same way | [ ] |
| 5 | After the fight, switch rings in the hub | No effects applied (log has no "Gear swap") | [ ] |
