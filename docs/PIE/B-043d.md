# PIE — B-043d: GAS stage 4 part 4, projectile and burst spells through the ability

**Branch:** `feature/B-043d-projectile-abilities-cloud` (cloud, UNBUILT, from `dev` with B-043b and B-043c in it).
**Proven by tests (once built):** `WoR.GAS.Abilities` "projectiles (B-043d)": which skills listen (projectile, loose projectile and burst yes; AOE, melee, no skill no); the Arrived / Dodged tags; an arrival on an actor with no running ability is not taken. End to end on the sim's montage-less Caster spell (`wor.Combat.InstantImpacts 1`, both combatants at the origin): one projectile deals the same damage at `wor.Abilities.UseGAS` 0 and 1 with one `Arrived` event; a 3-shot burst the same damage with 3 events; a foe moved out of the zone mid-flight takes 0 damage with one `Dodged` event. These end-to-end cases are new ground for the headless world (the projectile has to tick there): if they fail on the first build, check that before the routing. Worth a run too: `WoR.Balance.Sim.OneFight`, `WoR.Combat.HangFixes`, the Defense specs.

**Setup:** `wor.Abilities.UseGAS 1` for checks 2–8 (default 0). `Log LogWoR Verbose` shows `[Abilities] <caster>: projectile reached <target> through Event.Combat.Projectile.Arrived (cast entry N)`. `wor.Abilities.Print` shows `projectiles via GAS: listening / not listening (N arrived, M dodged)` per skill.
