# PIE — B-025: one shared start for every economy action

**Branch:** `refactor/B-025-economy-preamble` (in `dev`).
**Already proven:**
- The editor builds, and every test passes, including the new `WoR.Economy.Preamble` spec.
- The spec was written and passed on the old code first. It checks:
  - all 20 economy actions (dismantle, merge, buy, level up, downgrade…) refuse when there is no owner
  - they all refuse an owner that has no inventory or wallet
  - a normal owner can still dismantle a crystal and a weapon
- It all still passes after the change.

**What changed for the player:** nothing. Every economy action used to start with the same ~15 lines (is there an owner, does it have authority, does it have the right components), copied 20 times. Now they all call two shared helpers. If a component is missing, the warning in the Output Log names it, as before.

**Setup:** open the editor on `dev`, open the Output Log, and go where the merchant shop is.
