# PIE — B-524: what a run's chests and merchants give goes into the run's skills (stage S3b)

**Branch:** `feature/B-524-run-skill-sources` (in dev, built and tested on the desktop 2026-11-16).

**What it is:** D-224 (2): in a run, skills are bought or found. A chest's skill, a merchant's skill and a Mentor Token teach already learn through the store, which holds the run's list while a run is open (B-523). So they go into the run's skills, and the hub's list, set aside at the start, is not touched. No code changed: a new test proves it.

**Already proven by tests:** `WoR.Pool.Skills` (new case: a chest's ability and a spell bought back in the run go into the run list; the hub list set aside is unchanged; a quit brings the hub list back without the chest's ability). `WoR.Run.Skills` covers a teach. Full suite in the session note.

**Not proven:** a real chest and a real trial merchant in PIE.
