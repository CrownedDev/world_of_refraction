# PIE — B-214b: field skills part 2 (unlocks and the picker)

**Branch:** `feature/B-214b-field-unlocks` (in dev; written by the cloud, built and tested on the desktop 2026-11-14).
**Already proven by tests:** `WoR.Field.Skills` "the unlocks (B-214b)" (rank 3 / 7 thresholds, every listed aura, Teleport Void only, Generic and non-aura spells unlock nothing, a rank never falls, the save round trip, a character picking a type another character's spell unlocked) and the B-214a cases with Enhanced Sprint unlocked first. Not provable headless: the picker screen, a real spell rank-up through the economy, and the save on disk.
**Setup:** pull the branch, build, open the editor. **Editor step first:** mark one spell as an aura spell: open a Lightning (or any element) spell's data asset and set **Field Aura** to `Enhancement` (Crown's table decides the real ones; this is only to test). Play the hub with the leader. Give the party enough Skill Essence to level spells (`wor.Economy.*` cheats) and a character that owns that spell.

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | `wor.Field.Unlocks` | `ranks: none` (or only what your spells already reached) and `unlocked: none (the dash is everyone's)` | [ ] |
| 2 | On a Lightning leader, `wor.Field.Set Innate EnhancedSprint` | `Set: NotUnlocked`; the skill stays Dash | [ ] |
| 3 | Level the marked Lightning spell up to **D tier** (rank 3) | The log says `Lightning Enhancement aura reached rank 3` and `Lightning EnhancedSprint unlocked for every Lightning source` | [ ] |
| 4 | Open the party screen (`wor.UI.PartyControl`), press **Field skill...** | The picker opens: `Source: Innate (Lightning)`, `Movement: Dash ...`, `Unlocked for this source: Dash, Enhanced Sprint` | [ ] |
| 5 | Press the Movement button | It now says `Enhanced Sprint from Innate`; `wor.Field.Activate` while sprinting turns it on (B-214a check 5) | [ ] |
| 6 | Press Source until a source with another element (e.g. a Fire crystal in the weapon) | The unlocked list for it is only `Dash` | [ ] |
| 7 | Make a **different** character with a Lightning source the leader (one that never held the spell), open the picker | Enhanced Sprint is in its list and can be picked (account-wide) | [ ] |
| 8 | `wor.Field.Unlock Teleport Fire`, then `wor.Field.Unlock Teleport Void` | Fire: `refused (that element can't unlock it)`; Void: `unlocked` | [ ] |
| 9 | Save, quit to the menu, load; `wor.Field.Unlocks` | The ranks and unlocked types are still there | [ ] |
| 10 | Level the marked spell down (or give it away), `wor.Field.Unlocks` | Still unlocked (a rank once reached is kept, Q-214b) | [ ] |
| 11 | On a Generic with no element, open the picker | `Source: Innate (no element)`; only `Dash` | [ ] |

**Note for B-214a's sheet:** its Enhanced Sprint checks (5–9) now need the type unlocked first: `wor.Field.Unlock EnhancedSprint Lightning` (and Wind, Fire for check 8).

**Known limits (desktop review, 2026-11-14):** a spell rank raised by a path other than the spell level-up counts at the next scan of the store (a store change, a load, opening the picker, a pick), not at once. The unlock list is reset only by loading a save: after `wor.Save.Delete` in the same session the old unlocks stay until the game restarts (as the other account-wide lists do).
