# PIE — B-555: run levels kept in the hub (D-237, one-player stage 3b)

**Branch:** `feature/B-555-kept-run-levels` (in dev, built and tested on the desktop 2026-11-17). **Built unseen** (overnight run): nobody has looked at it in PIE yet.

**What it is:** the Mind / Body / Spirit levels a character earns in a run are kept in the hub the way gear is (D-237). A boss win, an extract or running out of wipes keeps the levels the run ended with, replacing the last run's; a quit (or a closed game) keeps the ones from before the run. The hub adds them; the next trial starts without them (from the class's base, as before). They are saved per character, and the title slot shows them.

**A wipe costs points:** at each party wipe every member loses 2 run points (`DefeatRules::WIPE_POINTS_LOST`, a tunable). Each point comes from a pillar rolled on its own among those with run points, so both can land on one pillar. A pillar's over-cap points go before its levels. Only run points are taken, so a pillar never drops below the class's base. The roll uses the run's seed. This replaces D-160's "a wipe takes no points"; the Prisms still drop as before.

**Not kept:** over-cap points and waiting (unspent) levels end with the run, as before.

**Editor steps:** none.
