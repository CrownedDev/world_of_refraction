# PIE — B-531: the Inventory tab; Edit on a worn entry; stacked lines

**Branch:** `feature/B-531-inventory-tab` (in dev, built and tested on the desktop 2026-11-16).

**What it is (D-230):**
1. **Inventory tab (step 1 of the four-step order, look only).** The loadout screen has a new first tab: Inventory, Equipment, Skills, Apparel, Cosmetics. It still opens on Equipment. The tab lists what the character owns and isn't wearing, from the real store, grouped under Weapons, Adapters, Evolutions and Crystals. Hovering or lighting a piece fills the details box. A on a piece opens the Add equipment window with that piece already picked: the same window, sockets and Y Confirm as "+ Add equipment". This step is for the look; check layout, words and icons, not the final design.
2. **Edit on a worn entry.** On Equipment, A (Enter) on an entry now asks the same Weapon / Adapter / Evolution question as "+ Add equipment", with the entry's own kind lit. Its own kind opens the existing window with what is there, to edit or swap the piece. Another kind replaces the entry, but only on Y Confirm. B before that leaves the entry as it was.
3. **Stacked lines.** Pieces that are exactly the same show as one line with a count ("Adapter Ring x5"). Exactly the same means: same asset and tier, both sockets empty, no picks, no rolled bonus. Choosing the line takes one of them. This applies in the Inventory tab and the Add window's weapon and adapter lists. Display only: each piece is still its own item.

**Already proven by tests:**
- `WoR.UI.LoadoutV2.Inventory`: the grouping, worn and in-use pieces left out, five empty adapters as one line of 5, a socketed one leaving the stack (4 plus its own line), a different tier or a picked piece apart.
- `WoR.UI.LoadoutV2` (model): Edit offers the other kind; cancel writes nothing; confirmed, an adapter replaces a weapon; a Generic's only weapon can't become an adapter (D-116).
- `WoR.UI.LoadoutV2` (screen), `WoR.UI.LoadoutApparel`: the Inventory chip and the LB / RB ring.

Full suite in the session note.

**No editor step.** Everything is built in C++.
