# PIE — B-186: zones

**Branch:** `feature/B-186-enemy-zones` (in `dev`).
**Already proven:** the editor builds and every test passes. `WoR.Trial.EnemyZone` (4 cases) checks four things: each tier is stronger than the one below; a fight takes the highest tier of the zones it starts in, tier 0 outside; a turned and scaled box still knows what is inside it; the same team is stronger in the higher zone, on top of the door's difficulty.

**What changed:** you can mark areas of a trial map as zones (`EnemyZone`, an invisible box). A zone has a tier, 0 to 4. A fight started inside it makes the enemies tougher: tier 1 gives 15% more max HP and damage, tier 4 gives 75% more. This stacks with the difficulty picked at the door. A zone also names a loot pool for later chests and drops (nothing reads it yet).

**Setup:** a trial level with two copies of the same enemy team (`FieldEnemyTeam`, or the same enemy pawn) far apart. Place an `EnemyZone` around each (scale the box to cover it): tier 1 around the first, tier 3 around the second. Output Log open.
