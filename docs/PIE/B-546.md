# PIE — B-546: one-player stage 1, look only (the title slots and the new-game picks)

**Branch:** `feature/B-546-title-slots-stage1` (in dev, built and tested on the desktop 2026-11-16).

**What this is:** the look, for Crown's check (D-228, D-229). The title shows character slots; the new-game screen shows each class's picks (D-228, 2026-11-17: no name box; a character is named by its class and element). **Begin still starts the old way** (as the lord matching the class and element); the weapon and crystal picks are not used until stages 3 and 4.

**Crown's tiles:** Light is the Light element. Unknown is Reality, which the game names Unknown (D-095). Broken Darkness sits after Darkness in the Refractor's list.

**Most slots:** `MaxCharacterSlots` under `[WoR.Title]` in `Config/DefaultGame.ini`. Unset means 12 (Generic, Resonator, and the Refractor once for each of the nine elements and Broken Darkness).

**Later, with a character figure:** it goes on the right and the slots move left (one value, `TitleScreenStyle::SlotsAlignment`).
