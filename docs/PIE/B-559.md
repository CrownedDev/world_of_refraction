# PIE — B-559: the new-game screen offers only the weapons that exist

**Branch:** `feature/B-559-stocked-weapon-picks` (in dev, built and tested on the desktop 2026-11-17). **Built unseen** (overnight run): nobody has looked at it in PIE yet.

**What it is:** a Generic's weapon list on the new-game screen showed all 12 weapon types, and nine of them gave nothing. It now shows only the types that have a weapon under **Picks | Pick Weapons** on the class table (`DA_Loadout_ClassDefaults`). Today those are Sword, Axe and Shield, in type order. Adding a row for a type later makes it show; nothing is hard-coded. With no rows at all, every type shows (as before).

Crystal types are not filtered: a crystal is a type and a tier, not an asset, so every type has an F-tier crystal.

No editor steps.
