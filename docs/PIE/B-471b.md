# PIE — B-471b: the recruit card

**Branch:** `feature/B-471b-talk-recruit-screens-cloud` (from B-471's branch; cloud, UNBUILT: build first).
**Already proven by tests:** `WoR.UI.RecruitCard` (headless) and `WoR.Party.RecruitCard` (the card's rules), once the desktop has run them.
**Setup:** build; start a run; find a recruitable character in the trial (a recruit spot, B-215, or one placed by hand; `wor.Party.PrintRecruitCard` prints its card).

| # | Do this | You should see | Result |
|---|---|---|---|
| 1 | With room in the party, walk up to the character and press Interact | The card: "Join for this run?", the name and class, the rule line, "Played by  NPC", one line "Invite for this run" | [ ] |
| 2 | Press A | They join for the run (`wor.Party.Print`: run only); the card closes; the prompt now says Dismiss | [ ] |
| 3 | Fill the party with NPC members, Interact with another character | One line per NPC "Invite: <name> steps out"; never your own character | [ ] |
| 4 | Pick one with Up / Down, press A | That member steps out, the new one joins | [ ] |
| 5 | Interact again and press B | The card closes; nothing changes | [ ] |
| 6 | (Co-op, if you can) a guest interacts with a recruit | The guest's request goes to the host as before (no card yet on the guest's screen) | [ ] |
